chore(ai): 🤖 AIツール設定の最適化

💡 What
- DuckDuckGo Search API 連携用スクリプトの検索バックエンドを `lite` に変更し、検索エラーを回避するようにしました。
- 毎週日曜日に、完全無料のAPIを利用して生成AIとCI/CD、オープンソースに関連するトレンドニュースを取得し、GitHub Issueとして作成する定期実行ワークフロー `ai-trends-weekly.yml` を追加しました。

🎯 Why
- `ddgs` パッケージのアップデートに伴うAPI仕様の変更に対応し、既存のPRコンテキスト検索機能の安定性を向上させるため。
- 最新のAI技術動向をリポジトリ内で継続的に把握し、開発フローの自動化と最適化に関する議論を活性化するため。

✨ Manual Setup
- 完全無料の API を利用するため、GitHub Secrets への新規トークン登録などの手動作業は不要です。
- Action が正常に Issue を作成できるよう、リポジトリの Settings > Actions > General > Workflow permissions にて `Read and write permissions` が有効になっていることを確認してください。

🛠 Rollback
- 追加されたワークフローファイル `.github/workflows/ai-trends-weekly.yml` およびスクリプト `scripts/ai-trends-weekly.py` を削除してください。
