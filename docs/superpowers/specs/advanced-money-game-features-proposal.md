# 提案：現実の経済を模倣した次世代マネーゲーム機能（モノポ向け拡張仕様）

## 概要

本ドキュメントは、従来の「モノポ」や「いただきストリート」が持つ不動産取引・株式投資の面白さをベースにしつつ、現実の複雑な金融・経済システムをシミュレートする新機能の提案です。
単なる盤上ゲームの枠を超え、プレイヤーが「生きた経済」や「現代のマネーリテラシー」を体験・学習できる教育的プラットフォームへと昇華させることを目的とします。

## 1. 従来ゲームの拡張（ベースとなる概念）

従来のゲームでは「土地を買う」「家を建てる」「独占する」といった一方向の投資が主でした。ここでは「いただきストリート」の要素も取り入れつつ、さらに発展させます。

- **エリア株と所有物件への投資による株価連動（相乗効果）**
  - 特定エリアの「株（インデックス）」を購入可能に。自分が所有する物件だけでなく、他人の物件に投資して配当を得られます。
  - 自分の物件を増資（投資）すると、そのエリアの株価が上昇する仕組みを導入し、キャピタルゲインの概念を学びます。

## 2. 現実経済を模倣した新機能（従来では考えられない機能）

### A. 信用スコア（クレジットスコア）とレバレッジ（負債の活用）

> **本セクションは「信用スコア・レバレッジ」機能の詳細仕様（スコアリング要因・金利計算式・自己破産トリガー・レバレッジ上限）の規範ドキュメントです。** 問題定義・要望概要は [issue-advanced-money-game-proposal.md「### B」](./issue-advanced-money-game-proposal.md) を参照してください。

単なる「所持金」だけでなく、プレイヤーに「信用スコア」を導入します。

- **機能:** 資産額、過去の負債返済履歴、安定した収益（毎ターンのキャッシュフロー）に基づいてスコアが変動。
- **教育的効果:** スコアが高いほど低い金利で銀行から資金を借り入れられ（レバレッジ）、より大きな物件に投資可能。逆に借金による自己破産のリスクを同時に学びます。「良い借金（投資のため）」と「悪い借金（消費・罰金のため）」の違いを体感できます。

### B. マクロ経済サイクルと中央銀行（金利とインフレ・デフレ）

固定の物価ではなく、ゲーム全体の経済状況がサイクルで変化します。

- **機能:** 「好景気（インフレ）」「不景気（デフレ）」の波が存在。中央銀行（システム）が定期的に「政策金利」を発表します。
- **教育的効果:** 金利が上がると借金の返済コストが増加し、物件価格が下落しやすくなります。逆に金利が下がると投資が活発化します。マクロ経済の波を読む力を養います。

### C. ESG投資とカーボンプライシング（環境・社会・ガバナンス）

ただ利益を追求するだけでなく、現代の投資トレンドである「社会貢献」を組み込みます。

- **機能:** 各物件には「ESGスコア」が設定されています（例：クリーンエネルギー施設は高スコア、旧式の石炭工場は低スコアだが初期利回りが高い）。
- **教育的効果:** 低ESG物件は高い「炭素税（環境税）」を課されたり、環境規制イベントで価値が暴落するリスクがあります。高ESG物件は税制優遇や低金利ローンの対象となります。持続可能な投資の重要性を学びます。

### D. 不動産の小口化（REITs）とクラウドファンディング

高額な物件（例：超高級ホテル）は1人では買えない仕様にします。

- **機能:** 複数のプレイヤーで共同出資（クラウドファンディング）して物件を所有し、出資割合に応じて家賃収入を分配（REITの概念）。
- **教育的効果:** 少ない元手でも分散投資によってリスクを抑えつつリターンを得る、現代的な投資手法を体験できます。

### E. リスクマネジメントと保険の概念

サイコロの運による理不尽な破産を防ぐための手段を提供します。

- **機能:** 「火災保険」「パンデミック保険」「株価暴落ヘッジ（プットオプション）」などの金融商品を銀行で購入可能。
- **教育的効果:** リスクに対する備え（ヘッジ）の概念と、保険料（掛け捨て）と期待値の計算を学びます。

### F. ダイナミックな税制と再分配（ソーシャルディビデンドの拡張）

既存の「GOマス通過で$150を獲得、他プレイヤーに$50を分配」というソーシャルディビデンドをさらに進化させます。

- **機能:** 所得（キャッシュフロー）や総資産額に応じた「累進課税」や「富裕税」を導入。集まった税金は「ベーシックインカム」として全プレイヤーに還元されます。
- **教育的効果:** 社会全体のセーフティネットの仕組みと、格差是正のメカニズムを体感します。

## 3. なぜこれが教材として効果的か

- **「失敗」を安全に経験できる:** 現実世界で破産や過剰なレバレッジによる失敗をすると致命的ですが、モノポの盤上であれば何度でもやり直せます。
- **システム思考の獲得:** 「風が吹けば桶屋が儲かる」ように、金利の変動が株価や不動産価格にどう影響するか、世界経済の連動性を直感的に理解できます。
- **意思決定スキルの向上:** 運の要素（サイコロ）に対して、いかに確率論とリスク管理（保険、分散投資）で立ち向かうかという、人生における重要な意思決定プロセスを訓練できます。
