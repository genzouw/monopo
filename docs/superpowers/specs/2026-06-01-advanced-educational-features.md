# 高度な金融教育・実社会模倣機能の提案仕様書

## 概要

本ドキュメントは、モノポWebアプリを単なるボードゲームから「実社会の経済・金融システムを体験し、マネーリテラシーを学ぶための高度な教育ツール」へと進化させるための新機能群を定義するものです。従来のモノポリーやいただきストリートなどの名作ボードゲームの優れたシステムを取り入れつつ、さらに現代の複雑な金融社会を模倣した革新的な機能を追加します。

## 1. 従来ゲームからの発展的機能 (Classic Extended)

### 1.1 株式とエリア投資・増資システム (株式市場の導入)

- **概要:** 各カラーグループ（エリア）ごとの株を購入できるシステム。自分のマスがなくても、他人のマスの増資に相乗りして配当（買い物料の一部）を得ることができる。
- **教育的効果:** 資本主義の基本である「株主と配当」の仕組み、分散投資の重要性、相場操縦（自分の所有エリアの株を買い占めてから増資して株価を吊り上げる）の模擬体験。
- **仕様:** ターン開始時に株の売買が可能。誰かが該当エリアに投資（家/ホテルの建設など）すると株価が上昇する。

### 1.2 独占・M&A・敵対的買収

- **概要:** 従来の「交渉による交換」だけでなく、市場価格の数倍（例: 3〜5倍）の金額を強制的に支払うことで、相手のマスを奪い取る「敵対的買収（Takeover）」機能。
  - **既存機能との関係:** 現行コードの `FORCE_BUY`（5倍買い）を基盤として拡張する形で実装する。新規システムとして一から再設計するのではなく、既存の5倍固定の価格倍率を「3〜5倍の可変レンジ」へ変更し、防衛策（ポイズンピル）のロジックを追加することで機能を発展させる。
- **教育的効果:** 企業買収（M&A）、キャッシュ・イズ・キングの原則（手元資金がないと買収されるリスク）、防衛策（ポイズンピルなど）の理解。

## 2. 実社会を模倣した革新的機能 (Modern Reality)

### 2.1 マクロ経済サイクル（好況・不況・インフレ・デフレ）

- **概要:** 数ターンごとに経済の「景気ステータス」が変動する。
  - **好況（インフレ）:** 物価（家屋の建設費、レンタル料）が上昇するが、GOマスでの収入も増加。
  - **不況（デフレ）:** 物価・収入が下落。現金の価値が相対的に高まる。
  - **金融危機:** 突然の株価暴落や、不動産価値の急落（ブラックマンデー的イベント）。
- **教育的効果:** インフレ時には現金を持たず資産（不動産・株）に替えるべき、デフレ時には現金が最強、といったマクロ経済の波乗りの学習。

### 2.2 金融機関・ローン・金利の変動

- **概要:** 銀行から借入（ローン）を行うことができるが、変動金利が適用される。
  - 借入限度額は所有資産（クレジットスコア）に依存。
  - 中央銀行（ゲームシステム）が政策金利を発表し、ローンの返済額や預金利息が変動する。
- **教育的効果:** レバレッジの力と恐ろしさ。金利上昇リスク（変動金利で借りすぎると破綻する）の学習。

### 2.3 税制と節税策 (Tax & Optimization)

- **概要:** 資産額や収入に応じて、定期的に「所得税」「固定資産税」「相続税（プレイヤー交代時など）」が徴収される（累進課税）。
- **教育的効果:** 税金が資産形成に与える影響の理解。また、特定のマス（例えば「教育基金」「再生可能エネルギー事業」）に投資することで控除を受けられるなど、合法的な節税の仕組みを学ぶ。

### 2.4 保険システム (Risk Management)

- **概要:** 不動産の火災（ランダムイベント）、訴訟、高額なマスへの支払いなどをカバーする「保険」を購入できる。
- **教育的効果:** リスク管理の重要性。保険料の掛け捨てと、実際に危機が起きたときのリターンのバランスを計算する力の育成。

### 2.5 新しいアセットクラス（暗号資産・ESG投資・スタートアップ）

- **概要:** 既存の不動産以外への投資先を用意。
  - **暗号資産:** ハイリスク・ハイリターンの投機商品。価格変動が極めて激しい。
  - **ESG投資・インフラ:** リターンは低いが、社会的評価（ソーシャルクレジット）が上がり、税制優遇や特定イベントでの罰金免除などの恩恵がある。
  - **スタートアップ投資 (VC):** サイコロの出目によって「ユニコーン企業」になり莫大な利益を生むか、倒産してゼロになる。
- **教育的効果:** ポートフォリオの多様化。現代の投資トレンドや、リスク許容度に応じた投資戦略の設計。

## 3. 実装のフェーズ分け

1.  **Phase 1:** 株式システムとエリア増資機能の導入（いただきストリート風のベース構築）。
2.  **Phase 2:** 銀行ローンシステムと変動金利、マクロ経済イベントの追加。
3.  **Phase 3:** M&Aシステム、税制・保険、および新規アセットクラスの導入。

この拡張により、モノポは単なる運ゲーではなく、戦略的な財務モデリングと意思決定が勝敗を分ける究極の教育プラットフォームとなります。
