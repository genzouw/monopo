# 高度な金融教育・実社会模倣機能の提案仕様書

## 概要

本ドキュメントは、モノポWebアプリを単なるボードゲームから「実社会の経済・金融システムを体験し、マネーリテラシーを学ぶための高度な教育ツール」へと進化させるための新機能群を定義するものです。従来のモノポリーやいただきストリートなどの名作ボードゲームの優れたシステムを取り入れつつ、さらに現代の複雑な金融社会を模倣した革新的な機能を追加します。

## 1. 従来ゲームからの発展的機能 (Classic Extended)

### 1.1 株式とエリア投資・増資システム (株式市場の導入)

- **概要:** 各カラーグループ（エリア）ごとの株を購入できるシステム。自分のマスがなくても、他人のマスの増資に相乗りして配当（買い物料の一部）を得ることができる。
- **教育的効果:** 資本主義の基本である「株主と配当」の仕組み、分散投資の重要性、相場操縦（自分の所有エリアの株を買い占めてから増資して株価を吊り上げる）の模擬体験。
- **仕様:** ターン開始時に株の売買が可能。誰かが該当エリアに投資（家/ホテルの建設など）すると株価が上昇する。

### 1.2 独占・M&A・敵対的買収

- **概要:** 従来の「交渉による交換」だけでなく、市場価格の数倍（例: 3〜5倍）の金額を強制的に支払うことで、相手のマスを奪い取る「敵対的買収（Takeover）」機能。
  - **既存機能との関係:** 現行コードの `FORCE_BUY`（5倍買い）を基盤として拡張する形で実装する。新規システムとして一から再設計するのではなく、既存の5倍固定の価格倍率を「3〜5倍の可変レンジ」へ変更し、防衛策（ポイズンピル）のロジックを追加することで機能を発展させる。
- **教育的効果:** 企業買収（M&A）、キャッシュ・イズ・キングの原則（手元資金がないと買収されるリスク）、防衛策（ポイズンピルなど）の理解。

## 2. 実社会を模倣した革新的機能 (Modern Reality)

### 2.1 マクロ経済サイクル（好況・不況・インフレ・デフレ）

- **概要:** 数ターンごとに経済の「景気ステータス」が変動する。
  - **好況（インフレ）:** 物価（家屋の建設費、レンタル料）が上昇するが、GOマスでの収入も増加。
  - **不況（デフレ）:** 物価・収入が下落。現金の価値が相対的に高まる。
  - **金融危機:** 突然の株価暴落や、不動産価値の急落（ブラックマンデー的イベント）。
- **教育的効果:** インフレ時には現金を持たず資産（不動産・株）に替えるべき、デフレ時には現金が最強、といったマクロ経済の波乗りの学習。
- **数理仕様:**
  - **更新周期:** 5ターンごとに景気ステータスを抽選で更新（通常→好況→金融危機→不況→通常 の遷移確率マトリクスで制御）
  - **景気乗数（`economy_factor`）:** 好況=1.3、通常=1.0、不況=0.7、金融危機=0.4（整数に丸め）
  - **計算式:** `adjusted_price = base_price * economy_factor`（端数は整数への切り捨て）
  - **範囲:** `economy_factor` の最小値=0.3 / 最大値=2.0（異常値防止のクランプ処理必須）
  - **金融危機イベント:** 株式アセットの現在価値を一律50%減（整数切り捨て）として即時反映

### 2.2 金融機関・ローン・金利の変動

- **概要:** 銀行から借入（ローン）を行うことができるが、変動金利が適用される。
  - 借入限度額は所有資産（クレジットスコア）に依存。
  - 中央銀行（ゲームシステム）が政策金利を発表し、ローンの返済額や預金利息が変動する。
- **教育的効果:** レバレッジの力と恐ろしさ。金利上昇リスク（変動金利で借りすぎると破綻する）の学習。
- **数理仕様:**
  - **基準金利（`base_rate`）:** 初期値=5%、毎5ターンで ±1〜3% をランダム変動（範囲: 1%〜30%）
  - **借入金利計算式:** `loan_interest = base_rate + spread * credit_score_factor`
    - `spread` = 2%（固定）
    - `credit_score_factor` = 所有マス数が全マスの25%未満=1.5 / 25〜50%=1.0 / 50%超=0.7
  - **借入上限:** `max_loan = total_asset_value * 0.5`（端数切り捨て）
  - **返済方式:** 毎ターン元利均等返済。`monthly_payment = loan_amount * loan_interest / (1 - (1 + loan_interest)^(-remaining_turns))`
  - **破産処理優先順位:** ①暗号資産→②スタートアップ投資→③株式→④不動産の順に強制売却。全売却後も債務超過の場合はゲームオーバー

### 2.3 税制と節税策 (Tax & Optimization)

- **概要:** 資産額や収入に応じて、定期的に「所得税」「固定資産税」「相続税（プレイヤー交代時など）」が徴収される（累進課税）。
- **教育的効果:** 税金が資産形成に与える影響の理解。また、特定のマス（例えば「教育基金」「再生可能エネルギー事業」）に投資することで控除を受けられるなど、合法的な節税の仕組みを学ぶ。
- **数理仕様（累進税率テーブル）:**

  | 課税所得（ターン収入） | 所得税率 |
  | ---------------------- | -------- |
  | 0〜1,000               | 0%       |
  | 1,001〜3,000           | 10%      |
  | 3,001〜6,000           | 20%      |
  | 6,001〜                | 30%      |
  - **固定資産税:** 毎10ターン、所有不動産の評価額合計の2%を徴収（整数切り捨て）
  - **節税控除:** ESG投資マス保有1件につき課税所得から500を控除（控除後の最低課税所得=0）
  - **税金計算タイミング:** GOマス通過時に確定・徴収

### 2.4 保険システム (Risk Management)

- **概要:** 不動産の火災（ランダムイベント）、訴訟、高額なマスへの支払いなどをカバーする「保険」を購入できる。
- **教育的効果:** リスク管理の重要性。保険料の掛け捨てと、実際に危機が起きたときのリターンのバランスを計算する力の育成。
- **数理仕様:**
  - **保険料:** 保険対象資産評価額の3%/10ターン（整数切り上げ）、ターン開始時に自動引落
  - **火災発生確率:** 不動産1件あたり毎ターン2%（ランダムイベント）
  - **保険金支払額:** 火災発生時に当該不動産の評価額100%を即時補填
  - **保険なし時の損失:** 火災発生時に評価額の80%を損失（残20%はスクラップ価値）
  - **最大補填額:** 保険金は1イベントあたり対象資産評価額の100%を上限とする

### 2.5 新しいアセットクラス（暗号資産・ESG投資・スタートアップ）

- **概要:** 既存の不動産以外への投資先を用意。
  - **暗号資産:** ハイリスク・ハイリターンの投機商品。価格変動が極めて激しい。
  - **ESG投資・インフラ:** リターンは低いが、社会的評価（ソーシャルクレジット）が上がり、税制優遇や特定イベントでの罰金免除などの恩恵がある。
  - **スタートアップ投資 (VC):** サイコロの出目によって「ユニコーン企業」になり莫大な利益を生むか、倒産してゼロになる。
- **教育的効果:** ポートフォリオの多様化。現代の投資トレンドや、リスク許容度に応じた投資戦略の設計。
- **数理仕様:**
  - **暗号資産価格変動モデル（対数正規分布）:**
    - 毎ターン価格更新: `new_price = current_price * exp(drift + σ * Z)` 、`Z ~ N(0,1)`
    - パラメータ: drift=0.0（期待値ニュートラル）、σ=0.3（ボラティリティ）
    - 乱数シード: ターン番号 + プレイヤーID のハッシュ値（再現性確保）
    - 価格範囲: 初期価格の10%〜1000%でクランプ（整数切り捨て）
  - **スタートアップ成功判定:** 投資ターンから5ターン後、サイコロ2個の合計が10以上でユニコーン（10倍返却）、2以下で倒産（全額消失）、それ以外は初期価格の±50%でランダム決着
  - **ESG投資リターン:** 毎10ターン、投資額の5%を配当として受取（整数切り捨て）

## 3. 実装のフェーズ分け

1.  **Phase 1:** 株式システムとエリア増資機能の導入（いただきストリート風のベース構築）。
    - **受け入れ基準:** 株の売買UI・エリアごとの株価表示・配当計算が正常に動作すること。家賃支払い時に配当が自動計算・株主に分配されること。
    - **非機能要件:** 株価更新処理は50ms以内に完了すること（プレイヤー4人・カラーグループ9つの標準構成時）。乱数シードが固定の場合に結果が再現可能であること。
    - **テスト観点:** 単体テスト（株価計算ロジック）・統合テスト（売買→配当の一連フロー）・1000ターンシミュレーションで資産偏差が合理的範囲（最大プレイヤーと最小プレイヤーの資産比が100倍を超えないこと）に収まること。

2.  **Phase 2:** 銀行ローンシステムと変動金利、マクロ経済イベントの追加。
    - **受け入れ基準:** 借入・返済UIが動作し、変動金利が5ターンごとに更新されること。景気ステータス（好況/通常/不況/金融危機）が遷移し、`economy_factor` が全価格計算に正しく反映されること。
    - **非機能要件:** 金利更新・景気変動の計算処理は30ms以内に完了すること。乱数シード固定時に全ターン結果が再現可能であること。
    - **テスト観点:** 単体テスト（金利計算式・景気乗数計算）・統合テスト（借入→返済→金融危機→破産処理の一連フロー）・1000ターンシミュレーションで破産発生率が10%未満であること（標準的プレイ戦略を前提）。

3.  **Phase 3:** M&Aシステム、税制・保険、および新規アセットクラスの導入。
    - **受け入れ基準:** 敵対的買収（FORCE_BUY拡張）・税金徴収（GOマス通過時）・保険購入・暗号資産/ESG/VC投資がすべて動作すること。Phase1・Phase2との連動（税制優遇・保険金・破産時の売却優先順位）が正しく機能すること。
    - **非機能要件:** 暗号資産価格更新処理（対数正規分布計算）は20ms以内に完了すること。全アセットクラスを保有した状態での1ターン処理が100ms以内に完了すること。
    - **テスト観点:** 単体テスト（各アセットの収益計算・税計算・保険支払計算）・e2eテスト（全フェーズ機能を使ったゲーム完走）・1000ターンシミュレーションで全プレイヤーが破産しないバランスが確認できること（意図的に悪手を打った場合を除く）。

この拡張により、モノポは単なる運ゲーではなく、戦略的な財務モデリングと意思決定が勝敗を分ける究極の教育プラットフォームとなります。
