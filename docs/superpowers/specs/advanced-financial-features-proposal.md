# 提案：monopoの現実経済シミュレーター化に向けた新機能実装Issue

## 概要

本Issueでは、既存のmonopo（モノポ）を単なるボードゲームから「マネーゲームを学習する教材」として昇華させるため、伝統的なゲーム（いただきストリートなど）で採用されている優れたシステムを導入しつつ、現実世界の金融・経済を模倣した全く新しい機能を提案します。
これにより、ユーザーは遊びながら投資、税制、マクロ経済、リスク管理の概念を学べます。

## 1. 伝統的ゲームからの機能取り込み（エリア投資・株式システム）

いただきストリート等の概念を取り入れ、不動産への直接投資に加えて「株式」を通じた間接投資システムを導入します。

- **エリア株（カラーグループ株）の売買**: プレイヤーは特定のカラーグループの株式を銀行から購入できます。
- **増資（資本投下）による価値向上**: 自分の土地に投資（増資）を行うことで、その土地の価値と家賃（とまり賃）が上がり、同時にそのエリアの株価も上昇します。
- **配当金システム**: 他のプレイヤーがそのエリアの物件に止まって家賃を支払った際、そのエリアの株を持っているプレイヤー（物件オーナーと支払者を除く）に、持ち株数に応じた配当金が支払われます。これにより「土地を持っていなくても相乗りで稼ぐ」という投資の基本が学べます。
- **敵対的買収（TOB）**: ターゲットとなるエリアの株式の過半数（51%など）を取得した場合、強制的に他人の物件を時価以上の価格で買収するシステム。現在実装されているFORCE_BUY機能（所持金要件のみで実行可能）を、株式保有条件付きで拡張する形での実装を想定しています。

### 定量仕様（フェーズ1）

| 項目                | 仕様                                                                             |
| ------------------- | -------------------------------------------------------------------------------- |
| 株式初期価格        | エリア購入価格の10%（例：購入価格200の場合、株価20）                             |
| 発行済み総株数      | 各エリア固定10株                                                                 |
| 1プレイヤー最大保有 | 発行済み総株数の50%未満（上限4株）                                               |
| 増資コスト・効果    | 投資額の20%が家賃・株価に上乗せ（例：100G投資 → 家賃+20G、株価+20G）             |
| 配当計算式          | `配当 = 支払い家賃 × 5% × (保有株数 / 発行済み総株数)`                           |
| 配当発火タイミング  | 家賃支払い即時（ターン集計ではなく都度精算）                                     |
| TOB発動閾値         | 対象エリア株式の51%以上を保有                                                    |
| TOB買収コスト       | 現在の物件時価の3倍                                                              |
| フェーズ1完了条件   | 株式売買・増資・配当・TOBの全機能がunit testおよびintegration testで動作確認済み |

**計算例（配当）**: 家賃100G、発行済み総株数10株、プレイヤーAが3株保有の場合 → 配当 = 100 × 5% × (3/10) = 1.5G（切り捨て → **1G**）

## 2. 現実経済を模倣した革新的な新機能（教材としての価値向上）

従来のボードゲームにはない、現実世界の複雑な経済システムをゲーム内に実装します。

### A. マクロ経済サイクル（景気変動・インフレ/デフレ）

- 数ターンごとに「好景気」「不景気」「インフレ」「デフレ」の波が訪れます。
- **インフレ時**: 物件価格や家賃が上昇し、現金の価値が目減りするため、資産（不動産・株）を持たないプレイヤーが不利になります。
- **デフレ時**: 現金の価値が上がり、物件価格が下落します。借金の負担が相対的に重くなります。

#### 定量仕様（マクロ経済サイクル）

| 項目             | 仕様                                               |
| ---------------- | -------------------------------------------------- |
| サイクル期間     | 8〜12ターンごとに1フェーズ切替（ベース10±乱数2）   |
| 景気フェーズ     | 好景気 / 普通 / 不景気 / インフレ / デフレ の5段階 |
| インフレ時係数   | 物件価格・家賃に×1.2（+20%）                       |
| デフレ時係数     | 物件価格・家賃に×0.8（−20%）                       |
| 好景気ボーナス   | 通過報酬・給与を×1.1                               |
| 不景気ペナルティ | 通過報酬・給与を×0.9                               |

### B. 信用情報（クレジットスコア）と動的ローンシステム

- 単なる「物件の抵当（お金をかりる）」ではなく、現代の金融システムである「ローンと信用度」を導入します。
- プレイヤーごとに**クレジットスコア**が設定され、毎ターンの確実な返済や資産増加でスコアが上がります。
- スコアが高いほど、銀行から多額の資金を「低金利」で借りられます。逆に返済が遅れるとスコアが下がり、高金利になったり追加の融資が受けられなくなります。

#### 定量仕様（クレジットスコア・ローン）

| 項目              | 仕様                                                                   |
| ----------------- | ---------------------------------------------------------------------- |
| 初期スコア        | 600                                                                    |
| 返済完了ボーナス  | +10〜+30（返済額1,000Gごとに+10）                                      |
| 延滞1ターン       | −50                                                                    |
| 資産増加ボーナス  | +5（1ターンあたり）                                                    |
| スコア上限/下限   | 最大850 / 最小300                                                      |
| 貸出限度額        | スコア × 100G（例：スコア700 → 最大70,000G）                           |
| 金利テーブル      | スコア≥750: 5% / 650〜749: 8% / 550〜649: 12% / <550: 15%              |
| 融資拒否ライン    | スコア400未満                                                          |
| フェーズ2完了条件 | 景気フェーズ切替・価格係数自動適用・クレジットスコア連動が全テスト通過 |

### C. 現実的な税制とESG投資（節税対策）

- **累進課税**: 一定ターンごとに決算があり、純資産や所得（家賃収入＋配当）が多いプレイヤーほど高い税率が課されます。
- **ESG（環境・社会・ガバナンス）投資**: ボード上に「クリーンエネルギー開発」や「社会貢献事業」への投資マスを設け、ここに投資することで強力な「税額控除（節税効果）」が得られるようにします。これにより、富裕層がなぜ慈善事業やESG投資を行うのかを体験として学べます。

#### 定量仕様（税制・ESG）

| 項目        | 仕様                                                   |
| ----------- | ------------------------------------------------------ |
| 決算頻度    | 10ターンごと                                           |
| 課税対象    | そのターン区間の収入（家賃収入＋配当）合計             |
| 累進税率    | 収入<5,000G: 10% / 5,000〜20,000G: 20% / >20,000G: 30% |
| ESG節税上限 | 課税額の最大40%まで控除                                |
| ESG投資単位 | 500G単位（1口あたり課税額の8%控除）                    |

### D. リスク管理と保険システム

- チャンスカード等のイベントで「自然災害（建物の損壊）」「病気・ケガ（高額な医療費）」といったランダムな損失が発生します。
- 事前に毎ターン少額の掛け金を支払って「火災保険」や「医療保険」に加入しておくことで、これらの被害を免除・軽減できます。「リスクヘッジのために固定費を払うか、資金を全て投資に回すか」というジレンマを生み出します。

#### 定量仕様（保険）

| 保険種別 | 保険料（毎ターン） | 補償内容                                     |
| -------- | ------------------ | -------------------------------------------- |
| 火災保険 | 200G               | 自然災害による物件損壊を全額補償             |
| 医療保険 | 150G               | 病気・ケガイベントの損失を最大3,000Gまで補償 |

### E. オルタナティブ投資・スタートアップ出資

- ボード上に「ベンチャーキャピタル」マスを追加。ハイリスク・ハイリターンのスタートアップに資金を投じられます。
- 大化けして莫大なリターン（IPO）をもたらすこともあれば、倒産して投資額がゼロになることもあり、分散投資の重要性を教えます。

#### 定量仕様（オルタナティブ投資）

| 項目              | 仕様                                                      |
| ----------------- | --------------------------------------------------------- |
| 投資単位          | 1,000G単位（最大10口まで）                                |
| IPO成功確率       | 20%（乱数）                                               |
| IPO時リターン     | 投資額の5倍                                               |
| 倒産確率          | 30%（乱数）                                               |
| 倒産時損失        | 投資額全額（0G）                                          |
| 維持（上場継続）  | 50%。翌決算まで保有継続                                   |
| フェーズ3完了条件 | 累進課税・ESG節税・保険・オルタナティブ投資が全テスト通過 |

## 実装のフェーズ分け提案

1. **フェーズ1**: 株式システムと増資・配当の実装（ゲーム性の拡張）
2. **フェーズ2**: クレジットスコア・銀行ローンシステム、およびマクロ経済サイクルの導入（信用と景気変動の学習）
3. **フェーズ3**: 税制・保険システム、およびオルタナティブ投資の追加（現実経済のシミュレーション）

## 期待される効果

このアップデートにより、monopoは「運と交渉のゲーム」から、「金融リテラシーを高める教育シミュレーター」へと進化します。子どもから大人まで、遊びながら実社会で役立つお金の教養（マネーリテラシー）を身につけられるようになります。
