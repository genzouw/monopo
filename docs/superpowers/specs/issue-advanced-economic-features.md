# 提案：現実経済を模倣した次世代マネーゲーム機能の導入（Issue）

## 概要
従来の「モノポ」や「いただきストリート」が持つ不動産取引・株式投資の面白さをベースにしつつ、現実の複雑な金融・経済システムをシミュレートする新機能の導入を提案します。
単なる盤上ゲームの枠を超え、プレイヤーが「生きた経済」や「現代のマネーリテラシー」を体験・学習できる教育的プラットフォームへと昇華させることを目的とします。

## 1. 従来ゲームの拡張（いただきストリート等の要素）
*   **エリア株と配当システム**: 特定エリアの株を購入可能にし、誰かがそのエリアに投資（増資）すると株価が上昇。他人の物件への投資を通じてキャピタルゲインとインカムゲインを得られるようにします。
*   **相乗り投資と敵対的買収**: 他プレイヤーの物件に対して強制的に買収を仕掛ける（例：5倍買い）機能や、逆に複数のプレイヤーで共同出資する仕組みを導入します。

## 2. 現実経済を模倣した新機能（従来にはない要素）
*   **マクロ経済サイクルと中央銀行**:
    *   好景気・不景気のサイクルを導入。中央銀行が定期的に「政策金利」を発表し、金利変動が物件価格や株価にダイレクトに影響します。
*   **信用スコアとダイナミック・レバレッジ**:
    *   プレイヤーの資産や過去の返済履歴に基づく「信用スコア」を導入。スコアに応じて借入金利や限度額が変動し、良い借金と悪い借金の違いを体感できます。
*   **ESG投資とカーボンプライシング**:
    *   各物件にESGスコアを設定。環境負荷の高い物件は炭素税などのペナルティリスクがあり、高スコアの物件は税制優遇を受けられるようにし、現代の投資トレンドを学びます。
*   **不動産の小口化（REITs）とクラウドファンディング**:
    *   超高額物件は1人では購入できず、複数プレイヤーで共同出資（REIT）することで、分散投資の重要性を学びます。
*   **リスクマネジメント（保険とデリバティブ）**:
    *   火災や金融危機などのブラックスワン・イベントに備え、保険やプットオプションを購入する仕組みを導入。リスクヘッジの概念を体験します。
*   **ダイナミックな税制と社会保障（ソーシャルディビデンドの拡張）**:
    *   累進課税や富裕税を導入し、集まった税金を「ベーシックインカム」として再分配。格差是正のメカニズムを体感します。

## 期待される教育的効果
*   安全な環境での失敗経験（破産や過剰なレバレッジのリスク体験）。
*   金利やインフレが経済全体に与える影響（システム思考）の理解。
*   確率とリスク管理に基づいた意思決定スキルの向上。
