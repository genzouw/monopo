# Issue: 現実経済を模倣した次世代マネーゲーム機能の追加提案

## 概要

従来の「モノポリー」や「いただきストリート」の要素（不動産取引、株式投資、独占など）をベースにしつつ、これらをさらに発展させ、現実の複雑な経済システムやマネーリテラシーを学習できる次世代の機能を提案します。
これは単なるゲームの枠を超え、プレイヤーが「生きた経済」を体験し、現代社会のマネーゲームを学ぶための教材的機能を目指すものです。

## 従来では考えられない新機能の提案

※これらの新機能は、既存の `FeatureFlags`（`src/game/types.ts`）と同様に、個別に有効/無効を切り替えられる機能フラグとして設計することを想定します。

### 1. 暗号資産（クリプト）とスマートコントラクト

- **概要**: 盤上に「暗号資産取引所」や「DeFiプロトコル」マスを配置します。
- **機能と教育効果**:
  - 法定通貨とは独立した高いボラティリティを持つ暗号資産を売買できます。
  - 「スマートコントラクト」機能により、特定の条件（例：特定のプレイヤーが特定のマスに止まった時）を満たした場合に自動で資金移動や所有権の移転が行われる契約を結べます。
  - プログラムされた金融（DeFi）の概念と、コードによる契約の自動執行の利点とリスク（ハッキングイベントなど）を学びます。

### 2. 人的資本投資（自己投資）と労働市場

- **概要**: プレイヤーは土地や株だけでなく、自分自身の「スキル」や「教育」に投資できます。
- **機能と教育効果**:
  - 大学マスやリスキリングイベントを通じて資金とターンを消費し、プレイヤーの「職業レベル」を上げます。
  - レベルが上がると、GOマス通過時などの基本給与が永続的に上昇したり、特定の税金が控除されたりします。
  - 資産運用だけでなく、「稼ぐ力（人的資本）」を高めることの重要性をシミュレートします。

### 3. 行動経済学に基づくバブルとパニック

- **概要**: プレイヤーの心理バイアスをシステムに組み込み、市場の非合理性を再現します。
- **機能と教育効果**:
  - 特定エリアの株が連続して買われると「FOMO（取り残される恐怖）」インジケーターが上昇し、ファンダメンタルズ（実際の収益力）を無視して価格が異常高騰する「バブル」が発生します。
  - 逆に、一つのネガティブニュースで連鎖的に売られる「パニック売り（暴落）」も発生。
  - 感情に流されず冷静に市場価値を見極める投資家心理（行動経済学）を学びます。

### 4. 敵対的買収（TOB）とM&A

- **概要**: 他プレイヤーの独占エリアを、強引に丸ごと買い取る仕組みです。
- **機能と教育効果**:
  - 既存の `FORCE_BUY`（強制買収）および `poisonPillActive`（ポイズンピル）の仕組みを拡張し、現在の市場価格に高いプレミアム（例：+50%）を乗せて「公開買付け（TOB）」を宣言できます。
  - 防衛側はホワイトナイト（他プレイヤーへの資金援助要請）やポイズンピル（`ACTIVATE_POISON_PILL` アクション）で対抗可能。
  - 企業の買収防衛策や、資産の適正評価、M&Aのダイナミズムをゲーム内で体験します。

### 5. 地政学リスクとグローバルサプライチェーン

- **概要**: 盤上の各エリアが「国」や「特定の産業（半導体、エネルギーなど）」を模しており、外部要因の影響を受けます。
- **機能と教育効果**:
  - 「関税引き上げ」「国際紛争による物流停止」「パンデミック」などのグローバルイベントが発生します。
  - 特定の産業エリアに投資が集中していると、外部ショックで一気に収益が落ち込むリスクがあります。
  - グローバルな分散投資の重要性と、世界情勢がどう経済に連鎖するか（サプライチェーンの分断など）を学びます。

## なぜこれが教材として効果的か

- これらの機能により、プレイヤーは単なる「サイコロの運」だけでなく、マクロ経済の動向、心理戦、自己投資、最新の金融テクノロジーといった複合的な要素を考慮して意思決定を行う必要があります。
- 現実世界では取り返しのつかない大失敗（バブル崩壊での破産など）を、安全なゲーム環境でシミュレーションすることで、実践的なマネーリテラシーが身につきます。
