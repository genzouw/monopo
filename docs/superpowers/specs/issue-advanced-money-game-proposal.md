# Issue: 従来のゲーム要素と現実経済を模倣した新機能の導入提案

## 概要

本Issueは、従来の「モノポ」や「いただきストリート」が持つ不動産取引・株式投資の面白さをベースにしつつ、現実の複雑な金融・経済システムをシミュレートする新機能の導入を提案するものです。
単なる盤上ゲームの枠を超え、プレイヤーが「生きた経済」や「現代のマネーリテラシー」を体験・学習できる教育的プラットフォームへと昇華させることを目的とします。

## 1. 従来ゲームからの機能拡張（ベース機能の強化）

「いただきストリート」などの要素を取り入れ、一方向の投資にとどまらない深い戦略性を実現します。

- **エリア株と相乗効果（インデックス投資・個別株）**
  - エリアごとの「株」を購入可能にし、自分が所有する物件だけでなく他プレイヤーの物件に投資して配当を得る仕組み。
  - 特定エリアの物件に増資（改築等）を行うと、そのエリアの株価が上昇する連動機能。
  - キャピタルゲイン（売買差益）とインカムゲイン（配当）の違いを学ぶことができます。

## 2. 現実経済を模倣した新機能（従来にはない画期的機能）

### A. 人的資本とキャリアパスの導入

スタート時の初期資金や毎ターンの収入が職業（キャリア）によって異なる機能。

- **機能:** 自己投資マスを設けて資格を取得したり、スキルアップすることで給与（GOマスでの収入）を増やすことが可能。
- **教育的効果:** 金融資産だけでなく、自身のスキル（人的資本）が最大の収入源になるという自己投資の重要性を学びます。

### B. 信用スコア（クレジットスコア）とレバレッジ

手持ち資金だけでなく「信用力」を数値化します。詳細な仕様・パラメータ設計（スコアリング要因・金利計算式・自己破産トリガー・レバレッジ上限）は [advanced-money-game-features-proposal.md「### A」](./advanced-money-game-features-proposal.md) が規範ドキュメントです。本セクションは問題定義・要望概要として位置づけます。

- **機能:** 資産状況、過去の借入・返済履歴に応じて信用スコアが変動。スコアが高いほど低金利で銀行から融資（ローン）を受けられます。
- **教育的効果:** 信用情報がいかに重要か、「良い借金（投資）」と「悪い借金（浪費）」の違い、そしてレバレッジによるハイリスク・ハイリターンを体感します。

### C. マクロ経済サイクルと金融政策（金利・インフレ）

ゲーム全体を取り巻く経済状況が動的に変化します。

- **機能:** 中央銀行（システム）が定期的に「好景気/不景気」のフェーズや「政策金利」を発表します。金利が上がると物件の価格が下がり、借入コストが増加します。
- **教育的効果:** 現実世界における金利変動が株価や不動産価格に与える影響（マクロ経済のダイナミズム）を肌で感じられます。
- **既存実装との接続方針:** 既存の `src/game/systems/macroEconomy.ts`（`ECONOMY_TRANSITION_MATRIX` / `transitionEconomy` による景気フェーズ遷移、`applyEconomyFactor` による景気乗数適用、`applyFinancialCrisisToStocks` による株価影響）を拡張します。政策金利・インフレ率の実装は以下の2方針から選択します：
  - **(A) 派生指標方式:** 既存の景気フェーズ・乗数から `policyRate` / `inflationRate` を算出し `reducer.ts` に公開する（既存 state を変更せず最小影響）。
  - **(B) 明示フィールド拡張方式:** `macroEconomy` の state に `policyRate` / `inflationRate` を追加し、`transitionEconomy` / `applyEconomyFactor` / `applyFinancialCrisisToStocks` で更新・通知する（より明示的だが変更箇所が多い）。

### D. スタートアップ投資（エンジェル投資）

盤上のマスに「スタートアップ企業」を配置し、少額の資金を投じます。

- **機能:** 高い確率で倒産して資金を失いますが、成功すれば上場（IPO）やM&Aによって数倍～数十倍のリターンが得られるマス。
- **教育的効果:** ベンチャー投資の不確実性と、ポートフォリオの一部として組み込むことの意味を学びます。

### E. グローバル経済と為替変動（多通貨システム）

ボードを「国内エリア」と「海外エリア」に分割し、それぞれ異なる通貨を使用します。

- **機能:** エリア間の移動や取引時に為替レートが適用されます。為替レートはターンの経過やイベントで変動します。
- **教育的効果:** 円安・円高といった為替変動が資産価値にどのような影響を及ぼすかを学びます。

### F. ダイナミック税制とセーフティネット（再分配）

社会の格差を調整するメカニズムを導入します。

- **機能:** プレイヤーの総資産額やターンごとの収入に応じた「累進課税」や「富裕税」を導入。徴収された税金は「ベーシックインカム」として全プレイヤーに再分配されます。
- **教育的効果:** 現実の税の役割と、社会全体を回す再分配の仕組みを直感的に理解できます。

## 教育的効果のまとめ

- **安全な失敗体験:** 現実では取り返しのつかない破産や過剰レバレッジの失敗を、ゲーム内で安全に経験できます。
- **複雑系システムの理解:** 「金利上昇 → 株価下落 → 不動産ローン負担増」といった連鎖的な経済の仕組み（システム思考）を獲得できます。
- **意思決定力の向上:** サイコロという「運」に対して、保険や分散投資、レバレッジのコントロールといったリスク管理で立ち向かうスキルを養います。

## 今後のアクションアイテム

1. 各機能（特に信用スコアとマクロ経済パラメータ）のバランス調整。
2. 既存の「モノポ」ルールへ段階的に導入するための拡張オプション（ON/OFF機能）の設計。
3. 複雑な経済指標を直感的に理解できるダッシュボードUIの作成。
