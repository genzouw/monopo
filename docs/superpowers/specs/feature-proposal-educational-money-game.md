# 「モノポ」の教育的マネーゲーム体験を強化する機能提案

## 背景と目的

「モノポ」は既にゲームとしての基盤を持っていますが、マネーゲームを通じて経済の仕組みを学習できる教材としての価値をさらに高めるため、従来のボードゲーム（モノポリー、いただきストリートなど）の良いところを取り入れつつ、現実世界のより高度で複雑な経済モデルを模倣する機能の追加を提案します。

## 1. 従来ゲームからの取り込み：株式とエリア株システム

### 概要

「いただきストリート」などで見られる、特定のエリアやグループ単位での株式（エリア株）購入と配当のシステムを導入します。

### 詳細機能

- **エリア（カラーグループ）株の購入**:
  - プレイヤーは各エリアの株を購入できるようになります。
  - 株価はエリア内の物件価格や家の数によって変動します。
- **買い物（買い物による配当）**:
  - 誰かがそのエリアの物件に止まって買い物（支払い）をした際に、支払い額の一定割合（例：10%）が株の保有比率に応じて株主に配当されます。
- **増資**:
  - 物件に家を建てると、そのエリアの株価が上昇します（増資効果）。
- **教育的効果**:
  - 不動産収益（インカムゲイン）だけでなく、株式投資による資本利得（キャピタルゲイン）や配当（インカムゲイン）の概念を学べます。

## 2. 現実を模倣した新規機能の提案

ここからは、従来のゲームにはない、現実世界のより高度な経済モデルを模倣する機能の提案です。

### 2.1 変動金利ローン（レバレッジと負債の管理）

既存の「物件の抵当」以外に、銀行から現金を借りることができるローンシステムを導入します。

**詳細機能**

- **借入限度額**: 総資産額（現金＋物件価値）に対する一定の割合まで借り入れが可能。
- **変動金利**: ゲーム内のターン数や後述の「マクロ経済サイクル」に応じて金利が変動します。
- **返済**: GOマスを通過するごとに、所持金から自動的に利息が引き落とされます。元本については、プレイヤーが任意のタイミングで自発的に返済できるほか、特定のマス（銀行マスなど）に止まった際に強制的に一部返済を求められる場合があります。
- **教育的効果**:
  - レバレッジをかけて投資規模を拡大するメリットと、金利上昇による破産リスク（負債管理）を学べます。

### 2.2 マクロ経済サイクル（インフレ・デフレ）

ゲーム全体に「好況」「不況」「インフレ」「デフレ」といった経済サイクルを導入します。

**詳細機能**

- **景気変動**: 一定ターンごと、または特定のイベントマス（チャンスマス等）によって景気が変動します。
- **影響**:
  - **インフレ時**: 全体的に家賃（レンタル料）が上昇する一方、ローンの金利も高くなります。
  - **デフレ時**: 家賃が下落し、新規物件の購入価格が下がりますが、ローンの金利は低くなります。
- **教育的効果**:
  - マクロ経済の波に合わせた投資戦略の変更（不況時の現金保有、好況時の投資拡大など）の重要性を学べます。

### 2.3 損害保険システムとブラックスワンリスク

物件に対する災害リスクと、それをカバーする保険システムを導入します。

**詳細機能**

- **ブラックスワンリスク**: 「火災」「地震」などの大規模なマイナスイベント（チャンスカード等で発生）があり、対象エリアの家屋が失われたり、一時的に家賃収入が得られなくなったりします。
- **損害保険の購入**: プレイヤーは物件ごとに保険料を支払うことで、被害を無効化、または補填を受けることができます。保険料の支払タイミングはGOマス通過ごとの掛け捨て方式とし、有効期間は次のGOマス通過まで（1ラウンド）とします。未加入の物件にはブラックスワンリスクが適用されます。
- **教育的効果**:
  - リスク管理（ヘッジ）の概念と、ランニングコスト（保険料）のバランス感覚を養えます。

### 2.4 累進課税と社会還元システム

資産を蓄積したプレイヤーに対して、より高い税率を課すシステムです。

**詳細機能**

- **累進所得税**: GOマスを通過した際の社会配当（$150など）を受け取る際、総資産（現金＋物件価値）に応じて税金が引かれます。資産が一定額を超えると税率が跳ね上がります。
- **社会還元（再分配）**:
  - 徴収された税金は「公共基金（仮）」にプールされ、一定条件（例：特定のマスに止まった、最も資産が少ないプレイヤーがGOを通過した等）で他のプレイヤーに再分配されます。
  - 現在の「ソーシャル・ディビデンド（GOマス通過時に他プレイヤーに$50ずつ配布）」のルールをより現実の税と再分配の仕組みに発展させます。
- **教育的効果**:
  - 現代社会の税制の仕組みや、富の再分配について体感できます。
