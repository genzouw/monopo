## 💡 機能提案の背景

「monopo（モノポ）」を、現実の経済活動やマネーゲームの概念を学習できる「教育的教材」として進化させるための提案です。
「伝統的な不動産取引ゲーム」や「伝統的な資産運用ボードゲーム」で馴染み深い基礎的なメカニクスをベースとしつつ、さらに現代の複雑な金融システムや社会課題をシミュレートする、従来では考えられない革新的なマネーゲーム機能を追加します。

> 📎 **関連提案との整合性:** 本書が当初提案していた「伝統的な資産運用ゲームの基本機能の統合」（エリア独占と設備投資、株式相乗り投資）は `ISSUE_PROPOSAL_TRADITIONAL_AND_MODERN_MECHANICS.md` と重複するため、正規仕様は同書とします。また「AIアルゴリズム取引の導入」「ダークプールと情報の非対称性」は `ISSUE_PROPOSAL_NEXT_GEN_FINANCE.md`（想定フラグ `features.hft`）と、「中央銀行の量的緩和とインフレ税」は `ISSUE_PROPOSAL_ADVANCED_MONEY_GAME.md` および `ISSUE_PROPOSAL_EDUCATIONAL_ASSET_MANAGEMENT.md` のマクロ経済サイクル関連項目と、「ESGスコアとグリーンウォッシュ」は同2書のESG関連項目とそれぞれ重複するため、正規仕様はいずれも既存の各書とします。本書は新規性のある「プラネタリー・バウンダリー（地球限界）システム」に範囲を絞って位置づけます。

## 🎯 提案する機能の概要

1. **伝統的な資産運用ゲームの基本機能との整合:**
   - 詳細は `ISSUE_PROPOSAL_TRADITIONAL_AND_MODERN_MECHANICS.md` の「伝統的な資産運用ボードゲーム機能の導入」を参照してください。本書での追加提案・変更はありません。

2. **プラネタリー・バウンダリー（地球限界）システム（新規追加）:**
   - 全プレイヤーの過度な開発や経済活動が「環境負荷メーター」を押し上げ、一定値を超えると深刻な気候変動イベント（全プレイヤーの資産半減やゲームオーバーなど）が発生します。競争だけでなく、共有地の悲劇を避けるための協力（排出権取引やエコ投資）を強制します。想定フラグ: `features.planetaryBoundary`（OFF時: 環境負荷メーターの表示・更新、閾値イベント判定、資産価値・通行料へのペナルティ、対策コストの徴収を含め、本機能に関する処理を一切行わない。既存挙動と完全互換）。

## ⚙️ ゲーム内での具体的なメカニクス

- **プラネタリー・バウンダリーと共有地の悲劇:**
  環境負荷メーターは 0〜100 の範囲で管理し、初期値は 0 とします。高環境負荷エリア（`ColorGroup` のうち `red` / `yellow` / `blue` を指します）を開発するたびに1回の開発につき +5 上昇します（エコ化済みエリアの開発は後述のとおり半減）。加算の契機は、当該エリアの新規購入時と、家・ホテルの建設1軒ごと（`BoardSpace.houseCost` の支払い1回ごと）の2つです。`railroad` / `utility` は本メーターの加算対象に含めません。メーターは 100 を上限にクランプし、超過分は切り捨てます。メーターが 100 に到達したターンでは、収支確定後の終了処理で気候変動イベントを1回だけ発動し、全プレイヤーの資産評価額を一律50%減、以後3ターン（グローバルターン `turnCount` 基準。プレイヤーの手番回数ではないため、参加人数によってペナルティの実効長は変わりません）の間は通行料収入を50%減とするペナルティを課します。ここでいう「資産評価額」は現金（`Player.money`）と所有エリアの評価額（購入価格＋建物への投資額の合計）のみを対象とし、ローン残高（`Player.loanBalance`）をはじめとする負債側は減額しません。減額後の金額の端数は、姉妹書 `ISSUE_PROPOSAL_EDUCATIONAL_ASSET_MANAGEMENT.md` の規約に合わせて円未満切り捨てで統一します。イベント発動後はメーターを100に固定したまま**ラッチ状態**に入り、以後の開発によるメーター加算（エコ化済みエリアであっても）は一切反映されません。ラッチはグリーンテクノロジー投資（-10）または排出削減クレジットの償却（-3）でメーターが100未満に下がるまで解除されず、ペナルティが自動で解除された後もメーターは自然減少しないため、対策を講じない限りメーターは100に留まり続けます。ラッチ解除後は再び通常どおり加算が反映され、再び100に到達すると同イベントが再発動します。なお、ラッチ中はエコ化による上昇量の緩和（+5 → +2）も加算自体が発生しないため体感できず、効果はメーターが100未満に下がった後の開発から反映されます。
  メーターを引き下げる手段は次の2つです。
  - **グリーンテクノロジー投資マス:** 停止したプレイヤーが任意で $500 を寄付でき、寄付1回につきメーターを -10 します（同一ターンに複数人が寄付した場合は合算して適用）。効果は即時かつ恒久的です。なお、この $500 の寄付は環境負荷メーターの低下のみに作用し、`features.progressiveTax` の寄付控除（`src/game/systems/taxation.ts` の `Player.pendingDonation` および `MAX_DONATION_RATE`）の対象外とします。両機能が同時に有効な場合でも、本寄付は課税所得から控除されず、寄付上限の計算にも算入しません。
  - **エリアの「エコ化」:** 所有エリア単位で $1,000 を支払って適用する恒久的な状態変更です。適用後はそのエリアの開発によるメーター上昇量が半減（+5 → +2、端数切り捨て）します。エコ化を取り消す操作は無く、一度適用すると当該エリアには永続的に適用され続けます。
  - **排出権取引との関係:** 本書は新たな資産を追加せず、`ISSUE_PROPOSAL_ADVANCED_MONEY_GAME.md` の「ESG投資と排出権取引」で定義済みの排出枠・排出削減クレジット（保有・消費・市場売買の仕様）をそのまま流用します。本書固有の追加効果は、排出削減クレジットを償却した際に環境負荷メーターを1クレジットあたり -3 する点のみであり、既存の排出枠・排出削減クレジットの資産としての扱いは変更しません。したがって、この -3 の低下手段は `ISSUE_PROPOSAL_ADVANCED_MONEY_GAME.md` の「ESG投資と排出権取引」が実装済みであることを前提とします。同機能が未実装・無効な場合、メーターの低下手段はグリーンテクノロジー投資マス（-10）のみとなり、ラッチ状態を解除するのに毎回 $500 が必要で開発2回で再び100へ到達するため、想定バランスから外れます。`features.planetaryBoundary` を単独で有効化して運用する場合は、開発1回あたりの上昇量（+5）を引き下げるか、グリーンテクノロジー投資の寄付額（$500）を引き下げるなどの調整余地があるものとします。
  - **全員敗北（ゲームオーバー）の条件:** 気候変動イベントが通算3回発動した時点でゲームを即時終了し、全プレイヤーを敗北として扱います（優勝者は発生しません）。ただし順位付けは残し、終了時点の総資産（現金＋所有エリアの評価額－ローン残高）の降順で相対順位を確定します。この終了条件は既存の勝敗判定（他プレイヤーの全破産による勝利など）に優先し、両者が同時に成立した場合は本条件を適用します。


## 🎓 教材としての教育的効果

1. **持続可能性と共有地の悲劇:** プラネタリー・バウンダリーを通じて、無限の経済成長は不可能であり、個人の利益追求（競争）と全体の生存（協力）のバランスをどう取るべきかを実践的に学習できます。

## ⚖️ ゲームバランスへの影響と懸念点

- **環境メーターによる全滅リスク:** プレイヤー間の足の引っ張り合いが過ぎると全員敗北（ゲームオーバー）になる可能性があるため、協力関係を築くための交渉機能やチャット機能との連携が不可欠になります。
