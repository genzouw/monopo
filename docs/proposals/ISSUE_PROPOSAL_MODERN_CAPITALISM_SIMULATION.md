## 💡 機能提案の背景

「monopo（モノポ）」を現実の経済の動きやマネーゲームの概念を学習できる「教育的教材」として進化させるための提案フォーマットです。
従来の「伝統的な不動産取引ゲーム」や「伝統的な資産運用ボードゲーム」の枠を超え、現代資本主義の複雑なシステムをシミュレートする機能を提案してください。

> 📎 **関連提案との整合性:** 「空売り（ショート）」は、初期証拠金率40%・維持証拠金率25%・追証・強制決済・残債処理を数値付きで定義済みの `ISSUE_PROPOSAL_ADVANCED_STOCK_SYSTEM.md`（リポジトリ直下）に重複するため、実装時に参照する正規仕様は同書とし、本書はその教育的な言い換えとして位置づけます。「タックスヘイブン」も同書に税務調査発覚時の重加算税＋資産凍結という重複する提案がありますが、本書はこの既存仕様のうちペナルティ内容を「未申告資産のみの没収＋罰金」（資産凍結は伴わない）に置き換え、あわせて「未申告」「申告済み」の2状態管理と申告手数料による切替操作を拡張として追加提案するものです。「敵対的買収（TOB）とM&A」は `src/game/economy.ts` の `calculateForceBuyMultiplier`（`FORCE_BUY_MULTIPLIER_MIN`〜`MAX`＝3〜5倍、`FORCE_BUY_POISON_PILL_BONUS`＝+1倍）として、「マクロ経済サイクルと金利変動」は `src/game/systems/macroEconomy.ts`（`ECONOMY_FACTORS`・景気遷移）および `src/game/systems/loan.ts`（`LOAN_INTEREST_RATES`: 好況5%〜金融危機25%、固定12%）としてすでに実装済みです。したがって本書の新規性は、TOBの状態遷移の明文化、返済不能時（金利上昇の有無を問わず、GOマス通過時の利息計算後にローン残高が総資産を上回った時点）の即時破産ルールの追加提案、およびタックスヘイブンの申告状態管理の追加提案に限られます。

### 🎯 提案する機能の概要 (What)

現代資本主義における高度な金融メカニクスやマクロ経済のダイナミクスを再現する、以下の4つの新機能の導入を提案します。

1. **空売り（ショート）機能**：特定のエリアや株式の暴落を見越して利益を得る機能。
2. **敵対的買収（TOB）とM&A**：他プレイヤーのエリアや企業（店舗）を、市場価格を上回るプレミアムを支払うことで強制的に買収する機能（`calculateForceBuyMultiplier` として実装済み。本書では買収成立の状態遷移を明文化する）。
3. **マクロ経済サイクルと金利変動**：中央銀行の役割を持つNPCやシステムが政策金利を変動させ、プレイヤーの借入コストや資産価値（株価・地価）に影響を与える機能（景気サイクルと金利計算自体は実装済み。本書の新規性は返済不能時の即時破産ルールのみ）。
4. **タックスヘイブン（オフショア口座）**：オフショア口座への資産保有自体は合法的な資産保全・節税行為として扱うが、資産を「未申告」状態のまま保有した場合はゲーム内の違反行為（脱税）となり、発覚すると重いペナルティ（未申告資産の没収など）を受けるハイリスクなエリア・機能。オフショア口座への移動は複数回行うことができ、移動ごとに独立した「資金ロット」として記録される。各ロットは移動額を単位として「未申告」「申告済み」の状態を個別に持ち、申告手数料をロットごとに支払うことで、そのロットのみを前者から後者へ切り替えられる（他のロットの状態には影響しない）。

### ⚙️ ゲーム内での具体的なメカニクス (How)

- **空売り（ショート）機能**:
  - 証拠金率・追証・強制決済・残債処理は正規仕様 `ISSUE_PROPOSAL_ADVANCED_STOCK_SYSTEM.md` に準拠する：建玉取得時価額の40%（初期証拠金率）を証拠金として預けて空売りポジションを持ち、毎ターン終了時に証拠金維持率 = (証拠金残高 − 評価損) ÷ 建玉取得時価額 を評価する。維持率が25%（維持証拠金率）を下回ると追証が発生し、翌ターンの行動フェーズ終了まで（1ターン猶予）に入金がなければその時点の時価でポジションを強制決済する。
  - 強制決済後もなお評価損が証拠金残高を上回る場合、その差額を残債として計上する（残債が初期資金の2倍を超えた場合のみ自己破産処理で救済）。
  - 他プレイヤーによる「強制買収」や「増資」による株価上昇と組み合わせることで、踏み上げ（ショートスクイーズ）のリスクが生じる。
- **敵対的買収（TOB）とM&A**:
  - 既存実装 `calculateForceBuyMultiplier`（`src/game/economy.ts`）に準拠する：所有者が自分以外である単独所有のエリア（色グループとしての独占の有無は問わない。`src/game/reducer.ts` の `FORCE_BUY` は `propState.ownerId` の存在と非自分保有のみを判定条件とし、独占判定は用いていない。なお独占状態を判定する仕組み自体は `src/game/rules.ts` の `ownsFullColorGroup` として別途実装済みで、家賃2倍判定や建築可否判定にはすでに使われている）に対して、開発度に応じた時価の3倍〜5倍のプレミアムを支払うことで強制買収を仕掛けられる。買収は常に成立し、防衛側が拒否・延期することはできない。既存実装（`src/game/reducer.ts` の `FORCE_BUY`）ではプレミアムの60%（`toOwner`）が防衛側プレイヤーに即座に支払われ、残り40%は銀行（システム）に帰属し、それと同時にエリアの所有権が買収側へ移転する。
  - 防衛側は「ポイズンピル（新株予約権の無償割当て）」を発動することで、追加ボーナス（倍率 +1）分だけプレミアムを上乗せさせることができるが、これは買収コストを引き上げる効果のみであり、買収自体を拒否・延期する効果はない。
- **マクロ経済サイクルと金利変動**:
  - 景気サイクルと金利計算は既存実装（`src/game/systems/macroEconomy.ts` の景気遷移、`src/game/systems/loan.ts` の `LOAN_INTEREST_RATES`: 固定12%／変動は好況5%・通常10%・不況15%・金融危機25%）をそのまま用いる。本書はこの既存仕様を置き換えず、以下の「返済不能時の即時破産」ルールのみを拡張として追加提案する。
  - 銀行から借金をして投資を加速させるレバレッジプレイが可能になるが、GOマス通過時に以下の順序で「即時破産」を判定する処理を新規に追加する（既存の `checkNegativeMoney`（`src/game/reducer.ts`）が前提とする `money < 0` の判定条件には依存せず、独立した分岐として実行する。現金が非負のままでも本ルールで破産に至り得る）：①既存の `calculateInterest` で利息額を計算し `money` へ反映する（既存動作のまま。利息は元本の返済ではないため `loanBalance` はこの時点では据え置く）。②その時点の `loanBalance` と総資産（既存の `calculateTotalAssets` が対象とする現金・不動産に加え、暗号資産・VC・株式の評価額も合算した、本ルール専用の拡張後の値）を比較し、`loanBalance` が上回れば返済不能と判定する。③返済不能と判定した場合、既存の非不動産資産清算（暗号資産→VC→株式の順）で資産を現金化し `money` に充当する。④清算後の総資産で再度 `loanBalance` と比較し、なお返済不能なら既存の `forceSell` フェーズ（プレイヤーが売却する物件を選ぶ形式）を経ずに、非独占エリア → 独占エリアの順で物件を自動的に強制売却する（独占判定は既存の `ownsFullColorGroup`（`src/game/rules.ts`）を再利用する）。⑤物件売却後もなお不足する場合は、その不足額を残債として確定したうえで `isBankrupt` を true に設定し、破産処理を完了する。
- **タックスヘイブン（オフショア口座）**:
  - マップ上の特定の「タックスヘイブン」マスに止まると、資産の一部をオフショア口座に移動できる。1回の移動が1つの「資金ロット」を生成し、そのロットは移動額を単位として、移動直後は「未申告」状態となる。同一口座に複数回移動した場合、各ロットはそれぞれ独立した申告状態を持つ。
  - プレイヤーは、次の「税務調査」イベントカードが引かれるまでの間であれば任意のタイミングで、未申告のロットを1つ選び、そのロットの移動額に対する一定割合を申告手数料として支払うことで、選んだロットのみを「未申告」から「申告済み」へ切り替えられる（他の未申告ロットの状態は変化しない）。「税務調査」イベントカードが引かれた時点で、その時点の各ロットの申告状態を確定・固定し、発覚判定が完了するまでの間は申告操作を受け付けない（発覚判定の前に申告手数料を支払って未申告状態でのペナルティを回避することはできない）。「申告済み」のロットは合法な資産保全として扱われ、以降の税務調査の対象外となる。
  - 「税務調査」イベントカードが引かれた際、発覚確率30%（実装時のバランス調整で確定する暫定値）で脱税が発覚する。発覚した場合、その時点でオフショア口座に残っている「未申告」ロットの合計額を没収したうえで、その没収額の50%を罰金として追加徴収する（金額の端数は既存の金銭計算（`calculateInterest` 等）と同様に切り捨てる）。没収額・罰金の合計に現金が不足する場合は、本書の「返済不能時の即時破産」ルール（非不動産資産清算→再判定→物件自動売却→残債確定・`isBankrupt`設定の順序）に準じて処理する。「申告済み」ロットは没収・罰金の対象外とする。

### 🎓 教材としての教育的効果 (Why it is educational)

- **空売り**: 市場の下落局面でも利益を出せる手段を学ぶと同時に、利益は限定的（最大でも株価が0になるまで）である一方、損失は青天井（無限大）であるという「踏み上げ」の恐ろしさを実践的に学べる。
- **敵対的買収（TOB）**: 企業の価値（時価総額）や株主の権利、そして企業買収のダイナミズムについて理解を深められる。
- **マクロ経済サイクル**: 金利の変動が資産価格（不動産や株）に与える影響や、レバレッジの恐ろしさ（借金をして投資することのハイリスク・ハイリターン性）を体感できる。
- **タックスヘイブン**: 現実世界における富裕層の節税・脱税問題と、コンプライアンス違反がもたらす社会的な制裁やリスク（レピュテーションリスク）について議論するきっかけとなる。

### ⚖️ ゲームバランスへの影響と懸念点

- **初心者の破産リスクの増大**: 空売りの追証やレバレッジによる借金により、システムを理解していない初心者が一瞬で破産する可能性が高まる。そのため、初期状態では空売り・タックスヘイブンの申告状態管理・返済不能時の即時破産ルールといった新規追加ルール（既に実装済みで常時有効なTOB・マクロ経済サイクルは対象外）はロックし、「アドバンスドモード」として選択式にするか、段階的なチュートリアルを設ける必要がある。
- **プレイ時間の長期化**: 買収防衛策や複雑な金融計算が増えることで、プレイ時間が大幅に延びる懸念がある。UI上で損益シミュレーションを自動で提示するなど、計算の負担を減らすサポート機能が不可欠である。
