## 🎯 提案する機能の概要 (What)

伝統的なマネーゲーム（モノポリーやいただきストリート等）で採用されている「エリア独占による価値上昇」や「エリアに対する株式の相乗り」といった基本概念を取り入れつつ、単なるゲームの模倣に留まらず現実社会の高度な金融システムをシミュレートする以下の機能を提案します。

> 📎 **関連提案との整合性:** 本書のうち「エリア株の相乗り投資」は既存実装 `ColorGroupStock`（`src/game/types.ts:95-99`）、「マクロ経済サイクルと金利変動」は既存実装 `src/game/systems/macroEconomy.ts` の `ECONOMY_FACTORS`（景気遷移）および `src/game/systems/loan.ts` の `LOAN_INTEREST_RATES`（固定12%／変動は好況5%〜金融危機25%）、「敵対的買収（TOB）」は既存実装 `calculateForceBuyMultiplier`（`src/game/economy.ts:236`、時価3〜5倍＋ポイズンピル+1倍）としてすでに実装済みです。「インサイダー取引・SEC監査」は `ISSUE_PROPOSAL_TRADITIONAL_AND_MODERN_FINANCE.md` および `ISSUE_PROPOSAL_REALWORLD_ECONOMIC_SIMULATION.md` で既に提案済み（正規仕様は `ISSUE_PROPOSAL_ADVANCED_STOCK_SYSTEM.md`〈リポジトリ直下〉）であり、いずれも本書の新規性ではありません。したがって本書の新規性は、エリアのREIT化（証券化）そのもの、負債パッケージ化商品（CDO）の組成・売買、および中央銀行による量的緩和・引き締めという政策手段の追加提案に限られます。

1. **エリア独占と株式相乗りの進化（REITとM&Aの導入）**
   - 特定のエリアを独占し設備投資することで収益（通行料）を上げる基本機能に加え、エリア全体を証券化（REIT化）する機能。
   - 他プレイヤーの所有エリアであっても、既存実装の時価プレミアム方式（`calculateForceBuyMultiplier`）に基づき、敵対的買収（TOB）を行い経営権（所有権）を奪うシステム。

2. **信用取引（レバレッジ・空売り）と証券化・デリバティブ商品**
   - 現物取引だけでなく、証拠金を利用したレバレッジ取引や、他プレイヤーのエリアの価値下落を見越した「空売り（ショート）」機能。
   - 負債を裏付けとする証券化商品（CDO: Collateralized Debt Obligation）の組成と売買。先物・オプションのようなデリバティブ（原資産の価格変動に対する契約）とは異なり、原資産（ローン債権）のキャッシュフローそのものを裏付けとする証券である点に注意する。

3. **マクロ経済サイクルと中央銀行（金融政策）の介入**
   - 「好景気・不景気」の単なるランダムイベントではなく、中央銀行による量的緩和（QE）・引き締め（QT）が既存の景気遷移に介入するシステム。QE/QTは既存の `EconomyStatus`・`ECONOMY_FACTORS`・`LOAN_INTEREST_RATES` を置き換えず、既存の `ECONOMY_TRANSITION_MATRIX`（景気遷移確率）に対する遷移バイアスとしてのみ作用する（合成ルールの詳細は「⚙️ ゲーム内での具体的なメカニクス」の「マクロ金融政策（QE/QT）」を参照）。
   - プレイヤーは金利動向を予測し、固定金利（`FIXED_LOAN_RATE`、景気非連動）・変動金利（`LOAN_INTEREST_RATES`、景気連動）のローンを使い分ける必要がある。QE/QTは景気遷移の確率にのみ作用するため、固定金利には影響しない。

4. **情報の非対称性とインサイダー取引リスク**
   - 次のターンに起こる経済イベント（特定のエリアの暴落や暴騰）を「調査費」を払って事前に入手できる機能。
   - ただし、この情報を元に不自然な大口取引を行うと、一定確率で「SEC（証券取引委員会）」（`ISSUE_PROPOSAL_TRADITIONAL_AND_MODERN_FINANCE.md`・`ISSUE_PROPOSAL_REALWORLD_ECONOMIC_SIMULATION.md` と同一の米国型モデルで表記統一）の監査が入り、莫大な罰金と信用失墜（数ターン取引停止）のペナルティを受ける。

## ⚙️ ゲーム内での具体的なメカニクス (How)

- **M&A（敵対的買収）**: エリア株は誰でも購入可能（本提案の新規性はエリアのREIT化＝証券化そのもの）。買収の発動条件とプレミアム倍率は保有比率という新方式を導入せず、既存実装 `calculateForceBuyMultiplier`（`src/game/economy.ts:236`、時価3〜5倍）にそのまま準拠する。防衛側は「ポイズンピル（新株予約権の無償割当て）」を発動して `FORCE_BUY_POISON_PILL_BONUS`（+1倍）分のプレミアム上乗せを求めることができる（買収自体を拒否・延期する効果はない）。
- **REIT化（証券化、本提案の新規性）**: 対象カラーグループの全エリアをまとめて「REIT持分」として証券化する。既存の `ColorGroupStock`（1色単位・発行株数固定・値上がり益中心で配当なし）との違いは、(1) 配当原資を対象カラーグループの通行料収入合計とし、ターンごとに保有比率へ按分配当する点、(2) REIT持分自体は独立した株価を持たず、対象エリア群の `pricePerShare` 合計に連動して価格が決まる点の2点。
- **空売りと踏み上げ（ショートスクイーズ）**: 証拠金率は独自に定義せず、正規仕様 `ISSUE_PROPOSAL_ADVANCED_STOCK_SYSTEM.md`（リポジトリ直下、初期証拠金率40%・維持証拠金率25%）に準拠する。対象エリアに誰かが止まり株価が急騰し証拠金維持率が25%を下回った場合、追証が発生し、1ターン以内に入金できなければ同書の規定どおり強制決済される。
- **CDO（証券化商品）の組成・売買（本提案の新規性）**: 中央銀行が複数プレイヤーの既存ローン（`loan` 機能、`getLoanInterestRate` で金利算出）の債権を束ねてCDOを組成し、他プレイヤーに販売する。価格は原資産ローンの残元本合計を `getLoanInterestRate` の金利水準で割り引いた現在価値とする。CDO購入者は原資産ローンの利息収入を継続的に受け取れる一方、原資産の借入プレイヤーが破産した場合はCDOの保有比率に応じて元本を按分で損失計上する（連鎖リスクを明示し、現実のサブプライム危機に類する教育効果を狙う）。
- **マクロ金融政策（QE/QT）**: 一定ターンごとに中央銀行がQE（量的緩和）・QT（引き締め）・中立のいずれかを発表する。効果は既存の景気遷移確率 `ECONOMY_TRANSITION_MATRIX` に対する加算的バイアスに限定し、専用の追加金利・追加乗数は導入しない（政策効果と既存の景気効果の二重計上を避けるため）。具体的には、QE発表中は次回の `transitionEconomy` 判定で好況（`boom`）方向への遷移確率を、QT発表中は不況・金融危機（`recession`/`crisis`）方向への遷移確率を、各行の確率合計が1.0を保つよう他の遷移確率から比例的に移し替える形で底上げする。**この移し替えは、当該行内で既に非ゼロの列のみを対象とし、ゼロ列には確率を発生させない**（`ECONOMY_TRANSITION_MATRIX` が明示する「好況→金融危機、金融危機→好況への直接遷移は0」という不変条件を壊さないため）。したがって、`crisis` 状態でQEが発表された場合は `boom` 列（既存0）を経由せず `normal` 列のみを底上げし、`recession` 状態でQEが発表された場合も同様に `boom` 列（既存0）を経由せず `normal` 列のみを底上げする（`recession` 列・`crisis` 列から比例的に確率を移し替える）。`boom` 状態でQTが発表された場合は `crisis` 列（既存0）を経由せず `normal`・`recession` 列を底上げする。景気状態が実際に遷移した結果として、既存の `ECONOMY_FACTORS` による金額補正と、`getLoanInterestRate` が参照する `LOAN_INTEREST_RATES`（変動金利のみ）が連動して変化する。固定金利（`FIXED_LOAN_RATE`）は景気状態に依存しない既存仕様のため、QE/QTの影響を受けない。
- **インサイダー取引**: 「情報屋」マスに止まるかコストを支払うことで未来のイベント情報を取得。取得直後に当該エリアの株を大量売買した場合、10〜30%の確率で「監査」が発動し、取引利益の3倍を没収される。

## 🎓 教材としての教育的効果 (Why it is educational)

- **コーポレートガバナンスとM&Aの理解**: 時価に対するプレミアムを支払う敵対的買収が実体経済でどういう意味（経営権の掌握）を持つか、またそれを防ぐための企業防衛策（ポイズンピル）について実践的に学べる。
- **レバレッジリスクと追証の恐ろしさ**: 空売りによる理論上の「無限大の損失リスク（踏み上げ）」や、証拠金取引におけるキャッシュフロー管理の重要性を痛感できる。
- **マクロ経済と金利のメカニズム**: 金利の変動が資産価格や負債に与える影響（金融引き締めでバブルが弾けるメカニズム）を体感し、ニュースで報じられる中央銀行の政策の意味を理解できるようになる。
- **コンプライアンスとモラルハザード**: インサイダー取引がなぜ規制されているのか、情報の非対称性が市場の公平性をどう歪めるかを倫理的・実践的に学べる。

## ⚖️ ゲームバランスへの影響と懸念点

- **複雑性の増大**: 初心者には金融用語（TOB、空売り、追証など）が難解すぎるため、段階的に機能が解放されるシステムや、充実したチュートリアル（用語解説機能）が必須となる。
- **破産連鎖のリスク**: 空売り失敗時の強制ロスカットや、金利上昇によるローン破綻が連鎖し、ゲームが早期に終了（あるいは特定のプレイヤーが何もできなくなる）懸念がある。初心者向けには「セーフティネット（自己破産後の再建モード）」の導入を検討すべき。
