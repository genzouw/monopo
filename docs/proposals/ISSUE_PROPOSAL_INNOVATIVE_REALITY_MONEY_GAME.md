## 🎯 提案する機能の概要 (What)

伝統的なマネーゲーム（モノポリーやいただきストリート等）で採用されている「エリア独占による価値上昇」や「エリアに対する株式の相乗り」といった基本概念を取り入れつつ、単なるゲームの模倣に留まらず現実社会の高度な金融システムをシミュレートする以下の機能を提案します。

1. **エリア独占と株式相乗りの進化（REITとM&Aの導入）**
   - 特定のエリアを独占し設備投資することで収益（通行料）を上げる基本機能に加え、エリア全体を証券化（REIT化）する機能。
   - 他プレイヤーの所有エリアであっても、既存実装の時価プレミアム方式（`calculateForceBuyMultiplier`）に基づき、敵対的買収（TOB）を行い経営権（所有権）を奪うシステム。

2. **信用取引（レバレッジ・空売り）とデリバティブ市場**
   - 現物取引だけでなく、証拠金を利用したレバレッジ取引や、他プレイヤーのエリアの価値下落を見越した「空売り（ショート）」機能。
   - 負債をパッケージ化した金融派生商品（CDO）の組成と売買。

3. **マクロ経済サイクルと中央銀行（金融政策）の介入**
   - 「好景気・不景気」の単なるランダムイベントではなく、中央銀行による金利調整や量的緩和（あるいは引き締め）が行われるシステム。
   - プレイヤーは金利動向を予測し、固定金利・変動金利のローンを使い分ける必要がある。

4. **情報の非対称性とインサイダー取引リスク**
   - 次のターンに起こる経済イベント（特定のエリアの暴落や暴騰）を「調査費」を払って事前に入手できる機能。
   - ただし、この情報を元に不自然な大口取引を行うと、一定確率で「証券取引等監視委員会（SEC）」の監査が入り、莫大な罰金と信用失墜（数ターン取引停止）のペナルティを受ける。

## ⚙️ ゲーム内での具体的なメカニクス (How)

- **M&A（敵対的買収）**: エリア株は誰でも購入可能（本提案の新規性はエリアのREIT化＝証券化そのもの）。買収の発動条件とプレミアム倍率は保有比率という新方式を導入せず、既存実装 `calculateForceBuyMultiplier`（`src/game/economy.ts:236`、時価3〜5倍）にそのまま準拠する。防衛側は「ポイズンピル（新株予約権の無償割当て）」を発動して `FORCE_BUY_POISON_PILL_BONUS`（+1倍）分のプレミアム上乗せを求めることができる（買収自体を拒否・延期する効果はない）。
- **空売りと踏み上げ（ショートスクイーズ）**: 証拠金率は独自に定義せず、正規仕様 `ISSUE_PROPOSAL_ADVANCED_STOCK_SYSTEM.md`（初期証拠金率40%・維持証拠金率25%）に準拠する。対象エリアに誰かが止まり株価が急騰し証拠金維持率が25%を下回った場合、追証が発生し、1ターン以内に入金できなければ同書の規定どおり強制決済される。
- **マクロ金融政策**: 一定ターンごとに中央銀行が金利を発表。金利が上がるとローン返済額が増加し、レバレッジをかけているプレイヤーのキャッシュフローが悪化する。逆に金利が下がると不動産価格のバブルが発生しやすくなる。
- **インサイダー取引**: 「情報屋」マスに止まるかコストを支払うことで未来のイベント情報を取得。取得直後に当該エリアの株を大量売買した場合、10〜30%の確率で「監査」が発動し、取引利益の3倍を没収される。

## 🎓 教材としての教育的効果 (Why it is educational)

- **コーポレートガバナンスとM&Aの理解**: 時価に対するプレミアムを支払う敵対的買収が実体経済でどういう意味（経営権の掌握）を持つか、またそれを防ぐための企業防衛策（ポイズンピル）について実践的に学べる。
- **レバレッジリスクと追証の恐ろしさ**: 空売りによる理論上の「無限大の損失リスク（踏み上げ）」や、証拠金取引におけるキャッシュフロー管理の重要性を痛感できる。
- **マクロ経済と金利のメカニズム**: 金利の変動が資産価格や負債に与える影響（金融引き締めでバブルが弾けるメカニズム）を体感し、ニュースで報じられる中央銀行の政策の意味を理解できるようになる。
- **コンプライアンスとモラルハザード**: インサイダー取引がなぜ規制されているのか、情報の非対称性が市場の公平性をどう歪めるかを倫理的・実践的に学べる。

## ⚖️ ゲームバランスへの影響と懸念点

- **複雑性の増大**: 初心者には金融用語（TOB、空売り、追証など）が難解すぎるため、段階的に機能が解放されるシステムや、充実したチュートリアル（用語解説機能）が必須となる。
- **破産連鎖のリスク**: 空売り失敗時の強制ロスカットや、金利上昇によるローン破綻が連鎖し、ゲームが早期に終了（あるいは特定のプレイヤーが何もできなくなる）懸念がある。初心者向けには「セーフティネット（自己破産後の再建モード）」の導入を検討すべき。
