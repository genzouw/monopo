# monopo (モノポ) 拡張機能提案：高度な経済・金融システム

本ドキュメントは、「monopo（モノポ）」を単なるボードゲームから、**現実の経済や金融の仕組みを学ぶことができる教材（マネーゲーム）** へと進化させるための新機能提案をまとめたものです。
『いただきストリート』のような株式システムを基盤としつつ、さらに現代の経済概念を取り入れた革新的な機能を追加することを目的としています。

---

## 1. 株式と増資のシステム（エリア株システム）

『いただきストリート』で採用されている中核システムを導入し、プレイヤーの戦略性を大幅に向上させます。

### 1-1. エリア株（カラーグループ株）の売買

- **機能概要**: 各カラーグループ（エリア）ごとに「株」が存在し、プレイヤーは銀行で株を売買できるようになります。
- **効果**: エリア内の物件に投資されると、そのエリアの株価が上昇します。
- **配当**: 他のプレイヤーがそのエリアの物件に止まりレンタル料を支払った際、株の所有割合に応じてレンタル料の一部が配当金として株主に分配されます。
- **教育的価値**: 「株式投資」「配当（インカムゲイン）」「株価上昇（キャピタルゲイン）」の基本的な概念を学べます。

### 1-2. 増資（物件価値の向上）

- **機能概要**: 既存の「家・ホテルを建てる」システムを拡張・代替し、自分の物件に資本を投下（増資）して物件価値（レンタル料）を上げるシステム。
- **相乗効果**: 増資を行うと、そのエリアの株価が連動して上昇します。自分の株を持っているエリアを集中的に増資することで、資産を爆発的に増やす「集中投資」的な戦略が可能です。

---

## 2. 現実経済の模倣と金融リテラシー教育のための新機能

単なるゲームの模倣にとどまらず、現実の経済で起こる事象をシステムとして組み込みます。

### 2-1. 景気変動（ビジネスサイクル）

- **機能概要**: ゲーム全体に「好況（Boom）」「後退（Recession）」「不況（Depression）」「回復（Recovery）」の景気サイクルを導入します。
- **影響**:
  - **好況時**: 全プレイヤーのGO通過ボーナス増加、全体的な株価上昇、レンタル料のインフレ。
  - **不況時**: GO通過ボーナス減少、株価下落、レンタル料のデフレ、税率の引き上げ。
- **教育的価値**: マクロ経済の波と、それに合わせた投資タイミング（不況時に買い、好況時に売る）の重要性を学べます。

### 2-2. 銀行ローンと変動金利

- **機能概要**: 現在の「抵当に入れる（Mortgage）」だけでなく、銀行から現金を借り入れる「ローンシステム」を実装します。
- **金利の変動**: 景気変動に合わせて中央銀行（システム）が金利（政策金利）を調整します。好況時は金利が高く、不況時は金利が低くなります。
- **教育的価値**: 「借金（レバレッジ）を利用した投資」のメリットと、金利上昇による返済リスク（黒字倒産など）をリアルに体験できます。

### 2-3. 累進課税と資産税（Wealth Tax）

- **機能概要**: 既存の固定額の「所得税（Income Tax）」マスを廃止し、プレイヤーの**総資産額（現金＋物件価値＋株式）に応じた累進課税システム**を導入します。
- **影響**: 資産が多いトッププレイヤーほど高い税率が課され、ゲームの極端なワンサイドゲーム化を防ぐ役割（富の再分配機能）を果たします。
- **教育的価値**: 税金の再分配機能や、富裕層に対する税制の仕組みを学習します。

### 2-4. 敵対的買収（M&A / テイクオーバー）

- **機能概要**: 他プレイヤーの物件に止まった際、一定の条件（例：そのエリアの株を50%以上保有している等）を満たしていれば、現在の物件価値の5倍〜10倍といった「莫大なプレミアム（割増金）」を強制的に支払うことで、相手の同意なしに物件を買い取る（買収する）ことができます。
- **防衛策**: ターゲットにされたプレイヤーも、自ら増資をして企業価値（物件価値）を高めることで買収コストを跳ね上げ、防衛（ポイズンピル的な戦略）が可能です。
- **教育的価値**: 企業買収（M&A）のダイナミズムと、株主としての支配権の重要性を学べます。

### 2-5. 保険（インシュランス）システム

- **機能概要**: プレイヤーは毎ターン少額の保険料を支払うことで、「損害保険」に加入できます。
- **効果**: 恐ろしい高額物件に止まってしまった場合や、悪質なチャンスカードを引いた際の支払いを、保険会社（銀行）が一定割合肩代わりします。
- **教育的価値**: リスクヘッジとしての保険の役割と、掛け捨てによる固定費用のトレードオフを実感できます。

### 2-6. インフレーションとデフレーション

- **機能概要**: 市場に出回っている現金の総量（マネーストライ）に応じて、物価（物件価格や初期レンタル料）が徐々に変動します。
- **影響**: 誰もがローンを組み市場にお金が溢れるとインフレが進み、現金を持っているだけのプレイヤーは相対的に損をします（現金の価値が下がる）。
- **教育的価値**: 現金預金のリスクと、インフレヘッジとしての実物資産（不動産・株）保有の重要性を直感的に理解できます。

## 3. 今後のロードマップと実装アプローチ

これらの機能は一度にすべて導入するのではなく、フェーズを分けて段階的に実装することを提案します。

1. **フェーズ1（基盤構築）**: 「エリア株システム」と「配当」の導入。ボードのUIに各エリアの現在の株価を表示。
2. **フェーズ2（経済の波）**: 「景気変動」システムを導入し、ターン経過や特定のカードによって景気が変わるようにする。
3. **フェーズ3（高度な金融）**: 「ローンと金利」「累進課税」の導入。プレイヤーの資産画面をより詳細な「バランスシート（B/S）」形式で表示する。
4. **フェーズ4（企業闘争）**: 「敵対的買収」を導入し、終盤の逆転要素を強化。

本提案により、monopoは単なる運と交渉のゲームから、**「現実の資本主義と金融エコシステムを疑似体験できる最高の知育・教育プラットフォーム」** へと昇華します。
