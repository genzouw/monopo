## 🎯 提案する機能の概要 (What)

従来の「いただきストリート」や「モノポリー」に見られる「エリア独占」や「相乗り投資」の概念をベースにしつつ、現実の現代資本主義をよりリアルに模倣した以下の機能を追加します。

1. **エリア株と相乗り投資システム**
   特定のエリア（店舗群）の株を購入できるシステム。
2. **株主優待制度**
   株の保有数に応じた独自の優待メリット。
3. **TOB（敵対的買収）と買収防衛策**
   市場価格にプレミアムを上乗せしたTOB（株式公開買付）を宣言し、既存株主の任意応募を募る機能。応募後に閾値へ到達した場合は、応募しなかった少数株主分をスクイーズアウトで取得します。
4. **暗号資産（仮想通貨）市場とハイボラティリティ投資**
   ゲーム内の別市場として、極端な価格変動を伴う投資商品を追加。

> 📎 **関連提案との整合性:** 「エリア株と相乗り投資システム」は `src/game/economy.ts` の `features.stocks`（`STOCK_INITIAL_PRICE` / `DIVIDEND_RATE_PCT` / `getStockHoldingRatio`）としてすでに実装済みです。「TOB（敵対的買収）と買収防衛策」は `ISSUE_PROPOSAL_ADVANCED_STOCK_SYSTEM.md`（リポジトリ直下）のM&A・TOB定義に重複する提案があり、実装時に参照する正規仕様は同書とします。「暗号資産（仮想通貨）市場」は既存の `features.altAssets`（`src/game/systems/altAssets.ts`）としてすでに実装済みですが、実装済みなのは売買処理（`BUY_CRYPTO` / `SELL_CRYPTO`）とターン終了時の価格更新のみです。価格は初期価格の10%〜1000%にクランプされており（`CRYPTO_MIN_RATIO` / `CRYPTO_MAX_RATIO`）、価値がゼロになることはありません。「暗号資産取引所」マスやスマホUIからの購入、ハッキングイベントは未実装であり、後述の「⚙️ ゲーム内での具体的なメカニクス」では将来の設計案として記載します。したがって本書が新規に提案する範囲は「株主優待制度」と、TOB・暗号資産の既存実装に対するバランス調整（下記「⚖️ ゲームバランスへの影響と懸念点」の独占禁止法イベント・TOB手数料の引き上げ・暗号資産購入額の上限設定）です。

## ⚙️ ゲーム内での具体的なメカニクス (How)

- **エリア株と相乗り投資システム:**
  プレイヤーはマップ上の特定のエリアの株を銀行または証券マスで購入できます。他のプレイヤーがそのエリアのマスに止まって買い物（支払い）をした際、株の保有比率に応じて配当金が自動的に分配されます。
- **株主優待制度:**
  1つのエリアの株を一定割合（例: 30%以上）保有している場合、そのエリアでの自分の支払い額が割引・免除される、あるいは銀行マス通過時に追加の優待ボーナスがもらえるメカニクスです。
- **TOB（敵対的買収）と買収防衛策:**
  プレイヤーは他人が所有・独占している店舗に対して、現在の評価額の2倍〜3倍の資金（プレミアム）を提示するTOB（株式公開買付）を宣言できます。TOBへの応募は株主の任意ですが、応募後に閾値（例: 発行済み株式の2/3以上）へ到達した場合は、応募しなかった残りの少数株主の株式も規定の買取価格で強制的に取得（スクイーズアウト）します。成立条件・強制決済ロジックの詳細は正規仕様（`ISSUE_PROPOSAL_ADVANCED_STOCK_SYSTEM.md`）に委譲します。ただし、対象プレイヤーは「ポイズンピル（新株予約権の無償割当て）」などの防衛アイテムを消費することで、買収コストをさらに跳ね上げさせ、買収を阻止することが可能です。
- **暗号資産（仮想通貨）市場:**
  既存の `features.altAssets` により、ダイアログからの売買（`BUY_CRYPTO` / `SELL_CRYPTO`）とターン終了時の価格更新（初期価格の10%〜1000%にクランプ）はすでに実装済みです。以下は将来の設計案です。「暗号資産取引所」マスに止まった際、あるいはスマホ（UIメニュー）からいつでも購入可能にする、価格が数倍に跳ね上がる、あるいはハッキング被害などの極端な乱数イベントで一時的に大きく下落する、といった拡張を想定しています（現行の価格クランプ仕様により価値がゼロになることはありません）。

## 🎓 教材としての教育的効果 (Why it is educational)

- **インカムゲインとキャピタルゲインの理解:**
  配当（インカムゲイン）で地道に稼ぐ方法と、エリアの価値を高めて株価を吊り上げ売却する（キャピタルゲイン）方法の違いを実践的に学べます。
- **コーポレートガバナンスと買収のリアル:**
  TOBと防衛策の攻防を通じて、企業の過半数の権利を握ることの重要性や、敵対的買収の仕組み、経営権の保護といった高度な経済知識を体験できます。
- **リスクとボラティリティの体感:**
  暗号資産の極端な価格変動を通じて、「分散投資の重要性」や「ハイリスク・ハイリターンな金融商品の危険性と魅力」を身をもって学習できます。

## ⚖️ ゲームバランスへの影響と懸念点

- **資金力の格差拡大（スノーボール効果）:**
  資金のあるプレイヤーがTOBを連発すると、初心者が巻き返す手段がなくなる恐れがあります。これを防ぐため、「独占禁止法イベント（トッププレイヤーへの強制課税や買収制限）」の導入や、TOB実行時の手数料を高く設定するなどの調整が必要です。
- **運要素の増大:**
  暗号資産のボラティリティが高すぎると、堅実な経営戦略が運によって簡単に覆されてしまうため、純資産に対する購入可能額にキャップ（上限）を設けるなどのセーフティネットの導入が推奨されます。
