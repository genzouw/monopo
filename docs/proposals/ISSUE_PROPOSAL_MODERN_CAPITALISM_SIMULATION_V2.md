### 🎯 提案する機能の概要 (What)

従来の「モノポリー」や「いただきストリート」が持つ「エリア独占」「他プレイヤーへの投資（相乗り）」「増資（物件のアップグレード）」といった基本機能を踏襲しつつ、そこからさらに現代の複雑な金融資本主義・マクロ経済を模倣した以下の革新的な機能群を追加することを提案します。

1. **信用創造とレバレッジシステム（空売り・証拠金取引）**
2. **マクロ経済イベントと中央銀行（金利操作・量的緩和/引き締め・CBDC導入）**
3. **M&A（企業買収）と敵対的TOB（株式公開買付）、防衛策（ホワイトナイト等）**
4. **タックスヘイブン（租税回避地）とオフショア法人設立**
5. **ESG投資とグリーンボンド（環境配慮による株価プレミアム）**

これらの機能により、単なるすごろく的な資産運用ゲームから、現実の金融リテラシーを高度に養えるシミュレーターへと昇華させます。

### ⚙️ ゲーム内での具体的なメカニクス (How)

1. **信用創造とレバレッジシステム（空売り・証拠金取引）**
   - プレイヤーは現金の代わりに、エリア（株価）の一定割合を証拠金として差し出し、レバレッジをかけて投資（または空売り）を行える。
   - 株価が思惑と逆行した場合、追証（マージンコール）が発生。支払えない場合、強制的に資産が売却（ロスカット）される。
2. **マクロ経済イベントと中央銀行**
   - 定期的に「中央銀行」から金利発表がある。金利が上がると増資コストが増し、借入利息が急騰。逆に金利が下がると、資産バブルが発生しやすくなる。
   - CBDC（中央銀行デジタル通貨）が発行されるターンがあり、現金決済の透明性が上がる（脱税やタックスヘイブンの効果が一時的に無効化される）。
3. **M&A（企業買収）と敵対的TOB**
   - いただきストリートのような「相乗り」を発展させ、他プレイヤーのエリア（企業）の過半数株式を取得すると、そのエリアの支配権を強制的に奪える（敵対的TOB）。
   - 防衛策として、ポイズンピル（新株予約権の無償割当て）やホワイトナイト（第三者への友好的な新株発行）を発動可能にする。
4. **タックスヘイブンとオフショア法人設立**
   - マップ上の特定マスに「タックスヘイブンマス」を設置。そこに止まると、一定のコストでオフショア法人を設立でき、自エリアの収益にかかる税金（ゲーム内の維持費や所得税イベント）を大幅に削減できる。
   - ただし、金融当局による「査察イベント」で発覚すると巨額の罰金を科されるリスク（ブラック・スワン）が存在。
5. **ESG投資とグリーンボンド**
   - 環境・社会に配慮した投資（特定エリアのグリーン増資）を行うと、機関投資家（NPC）からの資金流入があり、そのエリアの株価が市場平均よりも高く維持される。

### 🎓 教材としての教育的効果 (Why it is educational)

- **リスク管理の実践:** 証拠金取引や空売りにおける無限大の損失リスク（踏み上げ）と追証の恐ろしさを、身をもって体験できる。
- **マクロ経済と金融政策の理解:** 中央銀行の金利政策が、どのように市場全体（株価、不動産価格、借入コスト）に波及するかをシステム的に学べる。
- **コーポレートガバナンスと資本の論理:** M&AやTOBの攻防を通じて、資本主義社会における「企業の所有権」と「株主の力」の現実を理解できる。
- **税制とコンプライアンス:** タックスヘイブンによる節税効果とその裏にある法的・社会的リスク（レピュテーションリスク）のバランス感覚を学べる。
- **現代トレンドの把握:** ESG投資といった最新の金融トレンドが、実際の資金還流にどう影響しているかをゲーム内で体感できる。

### ⚖️ ゲームバランスへの影響と懸念点

- **ルールの複雑化:** 新たな選択肢（空売り、TOB防衛策など）が増えるため、1ターンの考慮時間が長くなり、初心者には難しすぎる懸念がある。
  - **対策:** 初級・中級・上級といった難易度（ルールセット）設定を用意し、初級では伝統的なモノポリー・いたストのルールのみ適用、上級でマクロ経済やレバレッジを開放する「段階的ロック解除」方式を推奨。
- **破産の連鎖:** 追証やTOBによる一発逆転/一発退場が起きやすいため、ゲームのプレイ時間が極端に短くなるか、逆に膠着状態に陥るリスクがある。
  - **対策:** 中央銀行によるセーフティネット（緊急融資）枠を設けることで、即時ゲームオーバーを防ぎ、敗者復活のチャンス（再生手続き）を残す設計が必要。
