### 🎯 提案する機能の概要 (What)

従来のモノポリーやいただきストリートなどの「不動産取引」「株価相乗り」「エリア独占」「増資」の概念をベースとしつつ、さらに現代の現実的な資本主義社会を模倣し、マネーゲームの教材として効果的な機能を追加する提案です。具体的には以下の機能の導入を提案します。

1. **信用取引と空売り（ショート）機能**：株価の下落局面でも利益を出せる機能や、レバレッジをかけた取引。
2. **M&A（企業買収）とTOB（株式公開買付）**：他のプレイヤーが所有するエリアや企業を、市場価格以上のプレミアムをつけて強制的に買い取る機能。
3. **インフレ・デフレの景気サイクルと中央銀行による金利操作**：ゲーム内のマクロ経済状況が変化し、物価や不動産価格が連動するシステム。
4. **クラウドファンディングとスタートアップ投資**：未上場の新規事業（新しいマスやエリア）に対して初期投資を行い、成功すれば大きなリターンを得る機能。

### ⚙️ ゲーム内での具体的なメカニクス (How)

- **信用取引と空売り**：プレイヤーは一定の現金を証拠金として、他プレイヤーの株や特定のエリア株を空売りできる。エリアの価値が下がれば差額を利益として得られるが、増資などで株価が上昇した場合、追加の現金（追証）を支払う必要がある。これによりショートスクイーズ（踏み上げ）が発生する。
- **M&AとTOB**：特定のエリアを独占したい場合、市場価格の1.5倍〜2倍の金額を提示することで、他プレイヤーから強制的に株や不動産を買い取ることができる。防衛策（ポイズンピル）を事前に設定することも可能。
- **景気サイクル**：一定ターンごとに「好景気」「不景気」が切り替わる。好景気時は不動産収入が増加するが、中央銀行（システム）が金利を引き上げ、借金（負債）の返済コストが上昇する。
- **スタートアップ投資**：ゲーム序盤にランダムで発生する「新規事業イベント」に対し、複数プレイヤーで資金を出し合う。一定ターン後に成功・失敗が判定され、成功時は出資比率に応じて配当や新エリアの権利が得られる。

### 🎓 教材としての教育的効果 (Why it is educational)

- **リスク管理とヘッジの学習**：空売り機能を通じて、無限損失リスクや追証の恐ろしさ、そして下落相場でのリスクヘッジの手法を実践的に学べる。
- **企業価値と資本コストの理解**：M&AやTOBのメカニクスにより、「なぜ企業は買収されるのか」「プレミアムとは何か」といったコーポレートファイナンスの基礎を体験できる。
- **マクロ経済と金融政策の体感**：景気サイクルと金利変動を導入することで、インフレ/デフレが資産価値や負債に与える影響、中央銀行の役割を肌で感じることができる。
- **投資の本質**：スタートアップ投資を通じて、ハイリスク・ハイリターンの仕組みや分散投資の重要性を学ぶことができる。

### ⚖️ ゲームバランスへの影響と懸念点

- 初心者にとって機能が複雑になりすぎる恐れがあるため、「ベーシックモード」と「アドバンスドモード（教材モード）」に分け、段階的に機能をアンロックするなどの工夫が必要。
- 空売りや信用取引によってプレイヤーが早期に破産（退場）する確率が高まるため、救済措置（例えば「自己破産後の再起システム」など）を併せて検討する必要がある。
