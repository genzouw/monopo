## 💡 機能提案の背景

「monopo（モノポ）」を現実の資本主義社会の動きから学べる「教育的教材」として進化させるための提案です。
従来の不動産取引ゲームや資産運用ボードゲームが持つ「不動産取引」「株価相乗り」「エリア独占」「増資」といった基本システムを踏襲しつつ、現代の金融市場・企業買収・金融政策といった要素をゲーム内に取り込みます。

> 📎 **既存実装との整合性:** 「景気サイクル」は `features.macroEconomy`（`src/game/systems/macroEconomy.ts`）として、好況・通常・不況・金融危機の4状態を `ECONOMY_TRANSITION_MATRIX` で遷移させ、`ECONOMY_FACTORS`（好況1.3・通常1.0・不況0.7・金融危機0.4）を通行料などに乗じる形ですでに実装済みです。「中央銀行による金利操作」に相当する景気連動金利も `features.loan`（`src/game/systems/loan.ts` の `LOAN_INTEREST_RATES`）としてすでに実装済みです。また「スタートアップ投資」も `features.altAssets`（`src/game/systems/altAssets.ts` の `resolveVCInvestment`）として、単独プレイヤーによるVC投資（サイコロ2個の合計が10以上でユニコーン成立・10倍払い戻し、2以下で倒産、それ以外は部分回収）がすでに実装済みです。これら既存実装に対して本書が持ち込む新規差分は、後述の金利決定ロジックの見直し1点のみです。
>
> 📎 **関連提案との整合性:** 「信用取引と空売り」「M&A・TOB」は、リポジトリルート直下の `ISSUE_PROPOSAL_ADVANCED_STOCK_SYSTEM.md`（初期証拠金率40%・維持証拠金率25%・スクイーズアウト・ポイズンピル等を数値まで定義）を正規仕様とし、本書はそれを前提としたうえで「TOBの適用範囲の切り分け」のみを差分として扱います。「スタートアップ投資の共同出資（クラウドファンディング）化」は `docs/proposals/ISSUE_PROPOSAL_INNOVATIVE_WEALTH_SIMULATION.md` を正規仕様とし、本書では新規提案として扱いません。

### 🎯 提案する機能の概要 (What)

従来のモノポリーやいただきストリートなどの「不動産取引」「株価相乗り」「エリア独占」「増資」の概念をベースとしつつ、さらに現代の現実的な資本主義社会を模倣し、マネーゲームの教材として効果的な機能を扱います。既存の正規仕様・既存実装との重複を避けるため、本書が**新規提案として持ち込む差分は以下の2点**に限定します。

1. **TOBの適用範囲の切り分け（新規差分）**：TOBでは買付価格や買付期間等を公表し、他のプレイヤーに保有株式の応募を募る。**買付の対象は応募された株式に限る**こととし、応募されなかった株式の取得（スクイーズアウト）や、エリア・不動産の強制取得は、TOBとは区別したゲーム独自の別手続として扱う。正規仕様の `ISSUE_PROPOSAL_ADVANCED_STOCK_SYSTEM.md` がTOBにスクイーズアウトまで含めているのに対し、本書は用語と手続を分離する点が差分。
2. **景気連動金利を「金融政策型」に見直す（新規差分）**：現行の `LOAN_INTEREST_RATES` は好況5%・通常10%・不況15%・金融危機25%と、**不況ほど金利が上がる信用リスク型**のモデル。これを、中央銀行が景気過熱を抑えるために**好況時に利上げする金融政策型**へ見直し、好況時は不動産収入が増える一方で負債の返済コストも上がるトレードオフを成立させる。

なお、以下は本書では新規提案として扱わず、上記の前提として参照するに留めます。

- **信用取引と空売り（ショート）**：正規仕様は `ISSUE_PROPOSAL_ADVANCED_STOCK_SYSTEM.md`。本書は固有の差分を持たない。
- **スタートアップ投資・クラウドファンディング**：単独VC投資は `resolveVCInvestment` として実装済みで、共同出資への拡張は `docs/proposals/ISSUE_PROPOSAL_INNOVATIVE_WEALTH_SIMULATION.md` が正規仕様。本書は固有の差分を持たない。

### ⚙️ ゲーム内での具体的なメカニクス (How)

- **M&AとTOB**：特定のエリアを独占したい場合、市場価格の1.5倍〜2倍の買付価格を公表し、他プレイヤーに保有株式の応募を募る（TOB）。応募された株式は公表条件に従って買い付けるが、応募されなかった株式の取得は、スクイーズアウト等に相当する別手続として扱う。エリアや不動産の強制取得は、TOBと区別したゲーム独自の機能として扱う。防衛策（ポイズンピル）を事前に設定することも可能。
- **景気サイクルと金利（差分部分のみ）**：好況・通常・不況・金融危機の遷移と、景気乗数による不動産収入の増減は既存実装（`macroEconomy.ts`）のまま変更しない。本書の差分は変動金利の決定ロジックで、現行の `LOAN_INTEREST_RATES`（好況5%・通常10%・不況15%・金融危機25%）を反転させ、好況時ほど金利が高く、不況・金融危機時には利下げで景気を下支えする金融政策型のテーブルへ置き換える。これにより、好況時は不動産収入が増える一方で借金（負債）の返済コストが上がるというトレードオフが生まれる。固定金利（`FIXED_LOAN_RATE`）との使い分けの意味づけも、景気読みの巧拙が現れる選択として強化される。

### 🎓 教材としての教育的効果 (Why it is educational)

- **企業価値と資本コストの理解**：TOB（任意応募による買付）と、応募されなかった株式の強制取得（スクイーズアウト）を別手続として体験することで、「なぜ企業は買収されるのか」「プレミアムとは何か」「少数株主はどう扱われるのか」といったコーポレートファイナンスの基礎を、用語の意味を取り違えずに学べる。
- **マクロ経済と金融政策の体感**：景気サイクルと金利変動を導入することで、インフレ/デフレが資産価値や負債に与える影響、中央銀行の役割を肌で感じることができる。

### ⚖️ ゲームバランスへの影響と懸念点

- 初心者にとって機能が複雑になりすぎる恐れがあるため、「ベーシックモード」と「アドバンスドモード（教材モード）」に分け、段階的に機能をアンロックするなどの工夫が必要。
- 金利テーブルを金融政策型へ反転させると、好況時に借入を抱えたプレイヤーの返済負担が現行より重くなる。既存の `features.loan` を有効にした既存プレイとのバランス差が大きいため、反転テーブルは新たなフラグ配下に置くか、`FIXED_LOAN_RATE` の水準と併せて再調整する必要がある。
