### 🎯 提案する機能の概要 (What)

従来のモノポリーや「いただきストリート」の基本的な機能（エリア独占による価値向上、株の相乗り購入や増資による株価上昇）を取り入れつつ、さらに現代の複雑な金融システムや現実経済の仕組みを模倣した機能を追加します。
主な追加機能として、「信用取引（レバレッジ買い・空売り）」「敵対的買収（TOB）と企業防衛策（ポイズンピル）」「中央銀行デジタル通貨（CBDC）と金利変動」「タックスヘイブンによる節税とペナルティ」の導入を提案します。

### ⚙️ ゲーム内での具体的なメカニクス (How)

1. **エリア独占と株式相乗り（伝統機能の拡張）**
   - **エリア独占**: 同一エリアの不動産を独占的に所有することで、増資上限が解放され、通行料が相乗的に増加する。
   - **株式相乗り**: 自分が所有していないエリアの株を購入し、他のプレイヤーが増資した際に株価上昇の恩恵を受ける。

2. **信用取引（レバレッジ買い・空売り）**
   - 株価の一定割合（例: 30%）を証拠金として支払い、レバレッジをかけて株式を購入（レバレッジ買い）または空売りできる。
   - エリアの価値が下がれば空売りの利益になり、上がった場合は追加で現金を支払う（追証）必要がある。
   - 既存の「強制買収」や「増資」による株価上昇と組み合わせることで、踏み上げ（ショートスクイーズ）のリスクが生じる。

3. **敵対的買収（TOB）と企業防衛策（ポイズンピル）**
   - **TOB**: 市場価格よりも高いプレミアム価格を提示して、他プレイヤーの所有エリアを強制買収できる。
   - **ポイズンピル（企業防衛策）**: 買収ターゲットにされた場合、新株を割引価格で発行し、買収者の持分比率を低下させることで買収コストを上げ、防衛を図る。

4. **中央銀行デジタル通貨（CBDC）と金利変動（マクロ経済の導入）**
   - ゲーム内に「中央銀行」を設置し、ゲーム全体の資金供給量（マネーサプライ）と政策金利を定期的に変動させる。
   - 金利が高い場合は借入コストが上昇し、現金の価値が高まるが、金利が低い場合は不動産や株式への投資が活発になる。

5. **タックスヘイブンによる節税とペナルティ**
   - 特定のマス（タックスヘイブン）に止まるか、専用のカードを使用することで、資産をオフショアに移し、ゲーム内税金（所得税や資産税）を免れることができる。
   - ただし、監査イベント（マルサの査察など）が発生した際に発覚すると、莫大な罰金と信用低下（数ターンの行動制限）のペナルティを受ける。

### 🎓 教材としての教育的効果 (Why it is educational)

- **伝統機能の拡張**: 資産の集中投資による相乗効果と、分散投資（相乗り）によるリスクヘッジとリターンの共有という、投資の基本原則を学べる。
- **信用取引**: 空売りの無限損失リスク（踏み上げ）やレバレッジの危険性、証拠金取引の仕組みを実践的に学べる。
- **敵対的買収と企業防衛**: 企業買収のメカニズムや、防衛策のコスト（既存株主の価値希薄化など）を通じ、コーポレートガバナンスの基本を学べる。
- **CBDCと金利変動**: マクロ経済の基礎である金融政策が、資産価値や投資行動にどのように影響を与えるかを体感できる。
- **タックスヘイブン**: 租税回避の仕組みとそれに伴う法的・社会的リスク（コンプライアンス）を学べる。

### ⚖️ ゲームバランスへの影響と懸念点

- 信用取引やTOBは初心者には複雑で破産リスクが高いため、ゲームモードを「スタンダードモード（伝統機能のみ）」と「アドバンスモード（全機能開放）」に分けることを推奨。
- マクロ経済の変動（金利）がランダムすぎると理不尽なゲーム展開になるため、数ターン前に金利変動の「予兆」を示す情報（経済ニュースなど）を提示するシステムが必要。
- タックスヘイブンの監査確率は、ゲーム後半になるほど高まるように調整し、終盤の逆転要素として機能させるべき。
