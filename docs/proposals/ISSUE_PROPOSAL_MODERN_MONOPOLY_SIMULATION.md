## 🎯 提案する機能の概要 (What)

従来のモノポリーやいただきストリートに見られる「不動産購入・増資・株の配当」といった基本システムをベースにしつつ、より現実的で現代の資本主義経済を反映した以下の機能を追加します。

1. **空売り（ショート）機能**: 価値の下落を予想して利益を得る機能。
2. **敵対的買収（M&A / TOB）**: 既存の株の相乗りだけでなく、資金力を背景に他プレイヤーのエリアや企業を強制的に買収するシステム。
3. **中央銀行デジタル通貨（CBDC）とマクロ経済イベント**: インフレ・デフレの波をシステムとして発生させ、現金の価値が変動する仕組み。
4. **タックスヘイブン（租税回避地）**: ゲームボード上に特殊マスを設け、そこでの資産隠しとそれに伴うリスク（監査や制裁）を導入。

## ⚙️ ゲーム内での具体的なメカニクス (How)

- **空売り（ショート）機能**
  - プレイヤーは特定のエリアや株価に対して証拠金を支払い、空売りポジションを持てる。
  - エリアの価値が下がれば差額が利益になるが、上がった場合は追加で現金を支払う（追証）必要がある。
  - 「増資」による株価上昇と組み合わせることで、踏み上げ（ショートスクイーズ）のリスクが生じる。
- **敵対的買収（M&A / TOB）**
  - 他プレイヤーが所有するエリアや株式に対して、現在の市場価格の一定割合（例: 150%）を提示することで、強制的に所有権を奪うことができる。
  - 防衛策（ポイズンピルなど）のカードやアイテムも実装し、攻防を生み出す。
- **マクロ経済イベントとCBDC**
  - 定期的に「好景気（インフレ）」「不景気（デフレ）」が発生し、現金の価値（現金の購買力）や資産価格が全体的に変動する。
  - CBDCによるマイナス金利が導入され、現金をただ持っているだけでは資産が目減りするメカニクスを取り入れる。
  - 「景気状態（インフレ/デフレ）」と「CBDC政策金利」は独立した別々の変数として扱い、現金の購買力低下（目減り）を二重適用しないようにする。両者の具体的な更新タイミング・適用対象（現金残高／資産価格）・計算順序・丸め規則は、実装設計時に別途定義する。
- **タックスヘイブン**
  - 特殊なマスに止まることで、手持ちの現金を税務署（システム）から見えない形に変換できる。
  - しかし、「監査イベント」が発生した際に見つかると、莫大な罰金と1回休みのペナルティを受ける。

## 🎓 教材としての教育的効果 (Why it is educational)

- **空売りの無限損失リスク（踏み上げ）**や、相場下落局面でも利益を出せるヘッジ（リスク回避）の重要性を実践的に学べる。
- **M&Aの仕組み**を学ぶことで、企業の所有権（株）の重要性と、資金力に任せた乗っ取りの現実を体験できる。
- **インフレ・デフレとマイナス金利**を体験することで、「なぜ投資（資産を現金以外に替えること）が必要なのか」という現代のマネーリテラシーの根本を直感的に理解できる。
- **タックスヘイブンのリスクとリターン**をゲームとして体験し、現実社会での租税回避問題への関心や、コンプライアンスの重要性を学ぶきっかけになる。

## ⚖️ ゲームバランスへの影響と懸念点

- 初心者が空売りリスクやM&Aの防衛策を理解せずに破産する可能性が高まるため、初期状態では機能ロックするか、チュートリアルが必要。
- マクロ経済イベント（特にインフレ・デフレ）の変動幅が大きすぎると、運要素が強くなりすぎるため、事前に予兆（ニュースフラッシュ機能など）を出すことでプレイヤーが対策できる余地を作る必要がある。
- タックスヘイブンマスが強すぎると脱税ゲームになってしまうため、監査リスク（確率）の調整がゲームバランスの鍵となる。
